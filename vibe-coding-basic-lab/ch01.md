# 1장. 바이브 코딩 시작하기

> 이 장에서는 코드를 한 줄도 직접 치지 않고, AI와 대화해서 나의 첫 번째 파이썬 프로그램을 만든다.

## 이 장에서 배울 것

- 프로그램, 파이썬, AI 코딩 에이전트, 바이브 코딩이 무엇인지 알아본다.
- 파일·폴더·경로·터미널처럼 앞으로 계속 쓸 컴퓨터 기초를 익힌다.
- VS Code와 Claude Code를 설치하고 로그인한다.
- Claude Code와 대화해서 **자기소개 프로그램**을 만들고 실행한다.

### 이 장의 결과물

```
안녕하세요! 저는 홍길동입니다.
취미는 등산이고, 좋아하는 음식은 김치찌개예요.
만나서 반가워요!
```

내 정보를 화면에 출력하는 파이썬 프로그램 `hello.py`

## 1. 바이브 코딩이란?

### 1-1. 프로그램이란?

**프로그램**은 컴퓨터에게 시킬 일을 순서대로 적어 놓은 **작업 지시서**다. 요리 레시피를 떠올려 보자.

| 요리 레시피 | 프로그램 |
|---|---|
| 1. 물 500ml를 끓인다 | 1. 사용자에게 이름을 묻는다 |
| 2. 면과 스프를 넣는다 | 2. 이름 앞에 "안녕하세요"를 붙인다 |
| 3. 4분간 더 끓인다 | 3. 화면에 출력한다 |

사람은 "적당히", "알아서" 같은 말을 이해하지만, 컴퓨터는 그렇지 않다. 그래서 컴퓨터가 알아들을 수 있는 정확한 언어로 지시서를 써야 하는데, 이 언어를 **프로그래밍 언어**라고 한다.

### 1-2. 파이썬이란?

**파이썬(Python)** 은 가장 인기 있는 프로그래밍 언어 중 하나다.

- 영어 문장처럼 읽기 쉬워서 처음 배우기 좋다.
- 엑셀 자동화, 데이터 분석, 웹 서비스, 인공지능까지 거의 모든 분야에서 쓰인다.

```python
print("안녕하세요")
```

이 한 줄이 파이썬 프로그램이다. "화면에 `안녕하세요`를 **출력(print)** 하라"는 뜻이다.

### 1-3. AI 코딩 에이전트란?

**AI 코딩 에이전트**는 말로 요청하면 코드를 직접 작성하고, 파일을 만들고, 실행까지 해 주는 AI다. 이 과정에서는 Anthropic이 만든 **Claude Code**를 사용한다.

일반 AI 챗봇과는 다음과 같은 차이가 있다.

| AI 챗봇 | AI 코딩 에이전트 (Claude Code) |
|---|---|
| 코드를 **보여 준다** | 코드를 **내 컴퓨터에 파일로 만든다** |
| 내가 복사해서 붙여 넣고 실행해야 한다 | 직접 실행하고 결과를 확인한다 |
| 오류가 나면 내가 다시 설명해야 한다 | 오류를 스스로 보고 고친다 |

### 1-4. 바이브 코딩이란?

**바이브 코딩(Vibe Coding)** 은 코드를 직접 타이핑하는 대신, **만들고 싶은 것을 말로 설명하고 AI가 만든 결과를 확인하면서** 프로그램을 완성하는 방식이다.

집 짓기에 비유하면 다음과 같다.

- **나 = 건축주**: 어떤 집을 원하는지 설명하고, 완성된 집을 둘러보며 확인한다.
- **Claude Code = 시공사**: 설계하고, 벽돌을 쌓고, 문제가 생기면 고친다.

건축주가 벽돌 쌓는 법을 몰라도 집을 지을 수 있듯이, 코드를 몰라도 프로그램을 만들 수 있다. 다만 좋은 건축주가 되려면 **원하는 것을 정확히 설명하고, 결과를 꼼꼼히 확인하는 능력**이 필요하다. 이 과정에서 기를 능력이 바로 이것이다.

## 2. 꼭 알아야 할 컴퓨터 기초

### 2-1. 파일과 폴더

- **파일**: 내용이 담긴 문서 하나. 예) `hello.py`, `보고서.xlsx`
- **폴더**: 파일을 담는 상자. 폴더 안에 또 폴더를 넣을 수 있다.
- **확장자**: 파일 이름 끝의 `.py`, `.xlsx` 같은 부분. 파일의 종류를 나타낸다. `.py`는 파이썬 파일이다.

### 2-2. 경로

**경로(path)** 는 파일이 어디에 있는지 알려 주는 **주소**다.

```
macOS:   /Users/gildong/vibe-coding/hello.py
Windows: C:\Users\gildong\vibe-coding\hello.py
```

"사용자 폴더 안의 → `vibe-coding` 폴더 안의 → `hello.py` 파일"이라는 뜻이다. macOS는 `/`, Windows는 `\`로 폴더를 구분한다.

### 2-3. 터미널

**터미널**은 마우스 대신 **글자로 컴퓨터에게 명령하는 창**이다. 처음엔 낯설지만, Claude Code는 터미널에서 동작하기 때문에 기본 사용법은 알아 두어야 한다.

| 하고 싶은 일 | 명령 | 예시 |
|---|---|---|
| 지금 어느 폴더에 있는지 보기 | `pwd` | `pwd` |
| 폴더 안의 파일 목록 보기 | `ls` | `ls` |
| 다른 폴더로 이동하기 | `cd 폴더이름` | `cd vibe-coding` |
| 상위 폴더로 올라가기 | `cd ..` | `cd ..` |
| 새 폴더 만들기 | `mkdir 폴더이름` | `mkdir vibe-coding` |

> 💡 위 명령은 macOS 터미널과 Windows PowerShell에서 모두 사용할 수 있다.

### 2-4. "프로그램을 실행한다"는 것

`hello.py` 파일을 만들기만 해서는 아무 일도 일어나지 않는다. 레시피를 써 놓기만 하고 요리를 하지 않은 것과 같다. **실행**은 컴퓨터에게 "이 지시서대로 지금 수행하라"고 시키는 것이다.

```bash
python3 hello.py   # macOS
python hello.py    # Windows
```

## 3. 환경 설정

> ⚠️ 시작 전 준비물: 노트북, **Claude 유료 구독(Pro 이상) 계정**, 인터넷 연결

### 3-1. VS Code 설치

**VS Code**는 파일을 열어 보고 편집할 수 있는 무료 프로그램이다. Claude Code가 만든 파일을 눈으로 확인할 때 사용한다.

1. https://code.visualstudio.com 에 접속한다.
2. 내 운영체제(macOS/Windows)에 맞는 버전을 내려받아 설치한다.
3. VS Code를 실행한다.

### 3-2. 실습 폴더 만들기와 터미널 열기

1. VS Code 메뉴에서 **터미널 → 새 터미널**을 누른다. 화면 아래에 터미널 창이 열린다.
2. 아래 명령을 한 줄씩 입력하고 `Enter`를 누른다.

```bash
cd ~
mkdir vibe-coding
cd vibe-coding
pwd
```

3. 마지막 `pwd` 결과에 `vibe-coding`이 보이면 성공이다.
4. VS Code 메뉴에서 **파일 → 폴더 열기**를 눌러 방금 만든 `vibe-coding` 폴더를 연다.

> 💡 `~`는 "내 사용자 폴더"를 뜻하는 기호다.

### 3-3. Claude Code 설치

터미널에 운영체제에 맞는 명령을 붙여 넣고 `Enter`를 누른다.

**macOS**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows (PowerShell)**
```powershell
irm https://claude.ai/install.ps1 | iex
```

설치가 끝나면 **터미널을 닫았다가 새로 열고**, 설치가 잘 되었는지 확인한다.

```bash
claude --version
```

버전 번호가 출력되면 성공이다.

> ⚠️ 설치 방법은 바뀔 수 있다. 명령이 동작하지 않으면 공식 문서(https://docs.claude.com/en/docs/claude-code)의 설치 안내를 확인한다. Windows에서는 Git for Windows를 먼저 설치해야 할 수 있다.

### 3-4. 로그인과 첫 실행

1. `vibe-coding` 폴더에 있는지 `pwd`로 확인한다.
2. 터미널에 `claude`를 입력한다.
3. 화면 안내에 따라 테마를 고르고, **Claude 계정으로 로그인**한다. 브라우저가 열리면 로그인 후 승인 버튼을 누른다.
4. 이 폴더를 신뢰하는지 물으면 **Yes**를 선택한다.
5. 입력창이 나타나면 준비가 끝난 것이다.

> 💡 **터미널이 부담스럽다면** VS Code 왼쪽의 확장(Extensions) 메뉴에서 **Claude Code**를 검색해 설치한다. 채팅 창처럼 생긴 화면에서 Claude Code를 쓸 수 있다. Claude 데스크톱 앱에서도 Claude Code를 사용할 수 있다.

## 4. 실습: 나의 첫 파이썬 프로그램

이제 Claude Code와 대화해 본다. 먼저 VS Code로 실습 폴더를 연 다음, 아래 요청문을 Claude Code 입력창에 그대로 입력한다. 한국어로 편하게 말해도 된다.

### 4-1. VS Code로 실습 폴더 열기

터미널(macOS는 **터미널** 앱, Windows는 **PowerShell**)에서 `vibe-coding` 폴더로 이동한 뒤, `code .`을 입력한다.

```bash
cd ~/vibe-coding
code .
```

- `code`는 VS Code를 실행하는 명령이고, `.`은 **지금 있는 폴더**를 뜻한다. 즉 "지금 있는 폴더를 VS Code로 열어라"라는 뜻이다.
- VS Code가 열리면 왼쪽 탐색기에 `VIBE-CODING` 폴더가 보이는지 확인한다.
- VS Code 메뉴에서 **터미널 → 새 터미널**을 누른다. 새 터미널은 자동으로 `vibe-coding` 폴더에서 시작한다.
- 이 터미널에 `claude`를 입력해 Claude Code를 시작한다.

> 💡 macOS에서 `code: command not found`가 나오면, VS Code에서 `Cmd+Shift+P`를 누르고 **Shell Command: Install 'code' command in PATH**를 실행한 뒤 터미널을 새로 연다. Windows는 VS Code 설치 시 자동으로 등록된다.

### 4-2. 인사 나누기

```
안녕! 나는 코딩을 처음 배우는 사람이야. 앞으로 쉬운 말로 설명해 줘.
```

Claude Code가 어떻게 대답하는지 읽어 본다. 사람과 대화하듯 자연스럽게 이야기하면 된다.

### 4-3. 파이썬 설치 확인하기

```
이 컴퓨터에 파이썬이 설치되어 있는지 확인해 줘. 없으면 설치 방법을 알려 줘.
```

이때 Claude Code가 **명령을 실행해도 되는지 허락을 구한다**.

#### 권한 승인이란?

Claude Code는 내 컴퓨터에서 파일을 만들거나 명령을 실행하기 전에 먼저 허락을 구한다. 시공사가 벽을 허물기 전에 건축주에게 확인받는 것과 같다.

선택지는 대략 다음과 같다.

| 선택지 | 의미 |
|---|---|
| Yes | 이번 한 번 허락 |
| Yes, and don't ask again… | 같은 종류의 작업은 앞으로 묻지 않고 허락 |
| No | 거절하고, 대신 어떻게 할지 알려 주기 |

> ⚠️ **무엇을 하려는지 모르겠다면 바로 승인하지 않는다.** `No`를 고르고 "이 명령이 무슨 일을 하는지 먼저 설명해 줘"라고 물어보면 된다.

파이썬이 없다고 나오면 Claude Code의 안내를 따라 설치하거나, https://www.python.org/downloads 에서 내려받아 설치한다. Windows에서는 설치 첫 화면의 **"Add python.exe to PATH"** 를 반드시 체크해야 한다.

### 4-4. 자기소개 프로그램 만들기

`[ ]` 부분을 내 정보로 바꿔서 요청한다.

```
내 이름은 [홍길동], 취미는 [등산], 좋아하는 음식은 [김치찌개]야.
이 정보를 출력하는 파이썬 프로그램을 hello.py로 만들고 실행해 줘.
```

Claude Code가 파일을 만들고 실행한 결과를 보여 준다.

### 4-5. 파일이 진짜 생겼는지 확인하기

VS Code 왼쪽 탐색기에서 `hello.py` 파일을 클릭해 연다. AI가 만든 파일은 **내 컴퓨터에 실제로 저장된 진짜 파일**이다.

만들어진 코드는 대략 다음과 같은 모습이다. AI는 매번 조금씩 다르게 만들기 때문에 똑같지 않아도 괜찮다.

```python
# 자기소개 정보
name = "홍길동"
hobby = "등산"
food = "김치찌개"

# 화면에 출력하기
print(f"안녕하세요! 저는 {name}입니다.")
print(f"취미는 {hobby}이고, 좋아하는 음식은 {food}예요.")
print("만나서 반가워요!")
```

### 4-6. 코드 설명 듣기

```
방금 만든 코드를 한 줄씩 초등학생도 이해할 수 있게 설명해 줘.
```

설명을 들으며 아래 개념을 확인한다.

| 코드 | 이름 | 의미 |
|---|---|---|
| `# 자기소개 정보` | **주석** | 사람이 읽으라고 써 둔 메모. 컴퓨터는 무시한다. |
| `name = "홍길동"` | **변수** | `name`이라는 이름표가 붙은 상자에 `"홍길동"`을 넣는다. |
| `"홍길동"` | **문자열** | 따옴표로 감싼 글자 데이터다. |
| `print(...)` | **출력** | 괄호 안의 내용을 화면에 보여 준다. |
| `f"...{name}..."` | **f-문자열** | 문장 안의 `{name}` 자리에 변수 값을 끼워 넣는다. |

> 💡 **변수 = 이름표 붙은 상자.** 나중에 `name = "김철수"`로 상자 내용만 바꾸면, 출력되는 문장도 모두 바뀐다.

### 4-7. 내 손으로 직접 실행해 보기

이번에는 Claude Code가 아니라 내가 직접 실행해 본다. VS Code 메뉴에서 **터미널 → 새 터미널**을 하나 더 열고 입력한다.

```bash
python3 hello.py   # macOS
python hello.py    # Windows
```

Claude Code가 보여 준 것과 같은 결과가 나오면 성공이다. 🎉

### 4-8. 수정 요청해 보기

이제 프로그램을 바꿔 달라고 요청한다. 결과를 보고 → 요청하고 → 다시 확인하는 것이 바이브 코딩의 기본 흐름이다.

```
마지막에 "오늘도 좋은 하루 보내세요!"라는 문장을 추가해 줘.
```

```
출력할 때 위아래에 ===== 줄을 넣어서 명함처럼 꾸며 줘.
```

수정할 때마다 VS Code에서 `hello.py`가 어떻게 바뀌었는지 직접 열어 확인한다.

### 4-9. Claude Code 종료하기

종료 방법은 Claude Code를 어디에서 실행했는지에 따라 다르다.

**터미널(CLI)에서 실행한 경우**

작업이 끝나면 입력창에 `/exit`를 입력하거나 `Ctrl+C`를 두 번 누른다. 다음에 다시 시작할 때는 `vibe-coding` 폴더에서 `claude`를 입력하면 된다.

**VS Code 확장에서 실행한 경우**

확장에서는 `/exit`나 `Ctrl+C`를 쓰지 않는다. Claude Code 패널(탭)의 **X** 버튼을 눌러 닫으면 된다. VS Code 자체를 종료해도 함께 닫힌다.

- 대화 내용은 자동으로 저장된다. 다음에 패널을 다시 열면 **이전 대화 기록**에서 골라 이어서 작업할 수 있다.
- 새 주제로 처음부터 대화하고 싶다면 패널의 **새 대화** 버튼을 누른다.

| 구분 | 터미널(CLI) | VS Code 확장 |
|---|---|---|
| 시작 | `vibe-coding` 폴더에서 `claude` 입력 | VS Code로 `vibe-coding` 폴더를 열고 Claude Code 패널 열기 |
| 종료 | `/exit` 입력 또는 `Ctrl+C` 두 번 | 패널(탭)의 X 버튼 |
| 지난 대화 이어 하기 | `claude --continue` | 패널의 이전 대화 기록에서 선택 |

## 5. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| `claude: command not found` 또는 "인식할 수 없는 명령" | 터미널을 완전히 닫고 새로 연다. 그래도 안 되면 설치 명령을 다시 실행한다. |
| `code: command not found` 또는 "인식할 수 없는 명령" (`code .` 입력 시) | macOS는 VS Code에서 `Cmd+Shift+P` → **Shell Command: Install 'code' command in PATH**를 실행한다. Windows는 VS Code를 다시 설치하면서 "PATH에 추가" 옵션을 체크한다. 이후 터미널을 새로 연다. |
| 로그인 화면이 열리지 않는다 | 터미널에 표시된 주소를 복사해 브라우저에 직접 붙여 넣는다. |
| `python: command not found` | macOS는 `python3`로 입력한다. Windows는 파이썬을 다시 설치하면서 "Add python.exe to PATH"를 체크한다. |
| `No such file or directory` | `hello.py`가 있는 폴더에 있는지 `pwd`와 `ls`로 확인한다. |
| Claude Code가 엉뚱한 작업을 한다 | `Esc`를 눌러 멈추고, 원하는 것을 다시 설명한다. |
| 무슨 말인지 모르겠다 | Claude Code에게 "방금 한 말을 더 쉽게 설명해 줘"라고 요청한다. |

> 💡 **오류 메시지가 나오면 그대로 복사해서 Claude Code에게 붙여 넣는다.** 이것이 가장 빠른 해결 방법이다.

## 6. 정리

### 핵심 요약

1. **프로그램**은 컴퓨터에게 주는 작업 지시서이고, **파이썬**은 그 지시서를 쓰는 언어다.
2. **바이브 코딩**은 원하는 것을 말로 설명하고, AI가 만든 결과를 확인하며 프로그램을 완성하는 방식이다.
3. **Claude Code**는 파일 생성·실행 전에 허락을 구한다. 모르는 작업은 승인 전에 물어본다.
4. AI가 "완료했다"고 해도 **직접 파일을 열어 보고 실행해서 확인**하는 습관을 들인다.

### 용어 사전

| 용어 | 뜻 |
|---|---|
| 프로그램 | 컴퓨터에게 시킬 일을 순서대로 적은 지시서 |
| 파이썬 | 읽기 쉬운 프로그래밍 언어 |
| AI 코딩 에이전트 | 코드 작성·파일 생성·실행까지 해 주는 AI |
| 경로 | 파일이 있는 위치를 나타내는 주소 |
| 터미널 | 글자로 컴퓨터에게 명령하는 창 |
| 실행 | 프로그램에 적힌 지시를 컴퓨터가 실제로 수행하는 것 |
| 변수 | 값을 담아 두는 이름표 붙은 상자 |
| 문자열 | 따옴표로 감싼 글자 데이터 |
| 주석 | `#`으로 시작하는, 사람을 위한 메모 |
| 권한 승인 | Claude Code가 작업 전에 내 허락을 구하는 것 |

### 스스로 점검하기

- [ ] 터미널에서 `pwd`, `ls`, `cd`로 원하는 폴더에 이동할 수 있다.
- [ ] `claude`를 입력해 Claude Code를 시작하고 종료할 수 있다.
- [ ] Claude Code에게 요청해서 `hello.py`를 만들었다.
- [ ] VS Code에서 `hello.py`를 열어 내용을 확인했다.
- [ ] 터미널에서 직접 `hello.py`를 실행했다.
- [ ] 코드에서 변수와 `print`를 찾아 무슨 역할인지 말할 수 있다.
