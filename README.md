# AI 엔지니어 학습 로드맵: 바이브 코딩에서 모델 연구까지

## 개요 

이 로드맵은 코딩 경험이 없는 사람이 AI 코딩 도구로 첫 결과물을 만드는 단계에서 출발하여, LLM 응용 서비스 개발자, AI/ML 모델 개발자를 거쳐 AI 기법을 연구하고 대규모 시스템을 최적화하는 전문가에 이르기까지의 학습 경로를 네 단계로 정리한 것이다.

### 대상

- 코딩을 처음 시작하지만 AI 분야로 성장하고자 하는 비전공자·입문자
- 다른 분야 개발 경험은 있으나 AI/ML을 체계적으로 익히려는 개발자
- 현재 위치를 진단하고 다음에 무엇을 공부할지 정하고 싶은 학습자

중·고교 수준의 수학과 영어 독해 능력을 전제로 하며, 그 이상의 수학은 로드맵 안에서 필요한 시점에 다룬다.

### 구성

| 단계 | 이름 | 도달 수준 | 대표 산출물 |
|---|---|---|---|
| 1 | 바이브 코딩 | AI 도구로 동작하는 결과물을 만들고 배포할 수 있다 | 작은 웹 앱 1~2개 |
| 2 | LLM 응용 서비스 개발 | 기존 LLM에 데이터·도구를 연결한 서비스를 개발·평가·배포할 수 있다 | 챗봇·RAG·에이전트 서비스 |
| 3 | AI/ML 모델 개발과 운영 | 모델을 직접 학습·튜닝하고 데이터 파이프라인과 운영까지 책임질 수 있다 | 엔드투엔드 ML 프로젝트 |
| 4 | AI 기법 연구와 시스템 최적화 | 논문 기법을 구현·개선하고, 대규모 학습·추론 시스템의 효율을 높이며, 데이터·안전·아키텍처를 포함한 AI 시스템 전체를 설계할 수 있다 | 논문 재구현, 최적화 사례, 오픈소스 기여 |

## 단계별 학습 항목

### 1단계: 바이브 코딩

코딩 지식 없이 AI 코딩 도구로 동작하는 결과물을 만들어 보며 개발의 전체 흐름을 체험하는 수준

1. **AI 코딩 도구 입문** — ChatGPT/Claude 대화형 코딩, Cursor/Claude Code/GitHub Copilot 설치와 기본 사용법, 도구별 특성 비교
2. **요구사항을 말로 설명하기** — 만들고 싶은 것을 기능 단위로 쪼개기, 명확한 지시문 작성, 예시·제약 조건 제시, 단계별 요청
3. **첫 결과물 만들기** — 간단한 웹 페이지·계산기·할 일 앱을 AI와 함께 완성, 실행·확인·수정 반복 사이클 익히기
4. **생성된 코드 읽기·검증** — AI에게 코드 설명 요청하기, 변수·함수·흐름을 대략 따라가기, 기대 결과를 먼저 적고 정상·예외 입력으로 동작 확인, 오류 메시지를 AI에게 넘겨 해결하기, 수정 전후 결과 비교
5. **버전 관리와 공유** — GitHub 계정, 변경 기록(commit), 변경 확인(diff), 이전 상태로 복원하는 방법, GitHub에 공유(push), Vercel/GitHub Pages 등으로 결과물 배포
6. **1단계 포트폴리오** — 자기 문제를 해결하는 작은 프로젝트 1~2개 완성, AI가 만든 코드의 한계 체감(동작하지만 이해 못하는 지점 기록)

### 2단계: LLM 응용 서비스 개발

기존 LLM에 데이터와 도구를 연결하여 챗봇·RAG·에이전트 서비스를 개발하고 배포하는 수준

7. **파이썬 기초** — 문법, 자료구조, 함수, 클래스, 예외, 파일 입출력, 모듈/패키지, 가상환경
8. **개발 도구** — Git/GitHub 심화, 터미널(CLI), VS Code, Jupyter Notebook
9. **파이썬 중급** — 컴프리헨션, 제너레이터, 데코레이터, 타입 힌트, 비동기(asyncio), 테스트(pytest), 패키지 배포
10. **자료구조·알고리즘** — 코딩 테스트 대비(배열, 해시, 스택/큐, 트리, 그래프, DP), 시간 복잡도
11. **데이터 처리 기초** — JSON/CSV 다루기, pandas 기초, SQL 기초, 웹 크롤링/API 활용
12. **웹·API 기초** — 클라이언트/서버 구조, HTTP 요청·응답(메서드, 상태 코드, 헤더, JSON 본문), REST API 개념, API 키·토큰 인증, 환경 변수로 키 관리, requests/httpx로 호출 실습
13. **LLM 기본 이해** — 머신러닝 개념 입문(학습·일반화), 토큰·컨텍스트·임베딩, 주요 모델·API 비교, 비용·한계 이해
14. **프롬프트 엔지니어링** — 프롬프트 설계 패턴, 구조화 출력(JSON), Few-shot, Chain-of-Thought
15. **LLM API 활용** — OpenAI/Anthropic 등 API 호출, 스트리밍, 함수 호출(Tool Use), 멀티모달 입력, 작은 평가셋(질문·기대 답변 10~20개) 만들기
16. **RAG** — 임베딩, 청킹, 벡터 DB(Chroma/pgvector 등), 하이브리드 검색·리랭킹, 평가셋으로 RAG 적용 전후 품질·비용·응답 시간 비교
17. **에이전트 개발** — LangChain/LangGraph, MCP, 도구 연동, 멀티 에이전트, 메모리 관리, 평가셋으로 도구·단계 추가 시 품질·비용·응답 시간 비교, 작업 시나리오별 성공 기준, 도구 호출·실행 결과 검증
18. **LLM 평가(Evals) 심화** — 평가 데이터셋 체계적 구축, LLM-as-a-judge, RAG 평가(RAGAS 등), 회귀 테스트 자동화
19. **AI 안전·책임** — 프롬프트 인젝션 방어, 개인정보 보호, 환각 대응, 가드레일, 편향·규제(EU AI Act 등) 개요
20. **LLM 서비스 배포** — FastAPI 백엔드, Docker, 환경 변수·키 관리, 로깅·모니터링, 비용 관리, 클라우드(AWS/GCP) 기초
21. **2단계 포트폴리오** — 챗봇/RAG 서비스/에이전트 개인 프로젝트

### 3단계: AI/ML 모델 개발과 운영

모델을 직접 학습·튜닝하고, 데이터 파이프라인과 운영까지 책임지는 수준

22. **수학 기초 I** — 선형대수(벡터·행렬·고유값), 확률·통계(분포, 추정, 가설 검정)
23. **데이터 처리 심화** — NumPy, pandas 심화, Matplotlib/Seaborn, 데이터 전처리·EDA, 데이터 출처·중복·라벨 품질 확인
24. **머신러닝 기초** — 지도/비지도학습, 회귀·분류·군집, 모델 평가·검증(문제·타깃 정의, 베이스라인, 지표 선택, 학습/검증/테스트 분리, 교차 검증, 전처리 파이프라인과 데이터 누수 방지), 과적합·정규화, 실험 기록과 재현성(환경·설정·시드·결과), scikit-learn
25. **머신러닝 심화** — 앙상블(랜덤포레스트, XGBoost 등), 피처 엔지니어링, 하이퍼파라미터 튜닝
26. **수학 기초 II** — 미적분(미분·편미분·체인룰), 최적화(경사하강법) 기초
27. **딥러닝 기초** — 신경망·역전파·최적화, PyTorch, CNN, RNN
28. **딥러닝 심화** — Transformer, 전이학습, Hugging Face
29. **LLM 파인튜닝** — LoRA/QLoRA, 지시 튜닝(SFT), RLHF/DPO 개요, 평가·벤치마크, 로컬 모델 서빙(vLLM/Ollama), 전문 분야와 관계없이 모든 학습자가 사전학습 모델을 목적에 맞게 조정하는 과정을 경험
30. **전문 분야 선택** — 컴퓨터 비전 / NLP·LLM / 추천 시스템 / 시계열 중 택
31. **데이터 엔지니어링** — 데이터 파이프라인(Airflow), Spark 기초, 데이터 레이크/웨어하우스 개념, 피처 스토어, 데이터 품질 관리
32. **MLOps** — 실험 관리(MLflow/W&B), 데이터·모델 버전 관리(DVC), 모델 서빙·모니터링, 데이터·개념 드리프트 감지, 예측 품질·서비스 성능 모니터링, 배포 검증·롤백, 재학습 판단, CI/CD·파이프라인 자동화
33. **3단계 포트폴리오·실전** — Kaggle, 엔드투엔드 ML 프로젝트(데이터 수집→학습→배포), 논문 읽기 시작

### 4단계: AI 기법 연구와 시스템 최적화

논문의 기법을 구현·검증·개선하고, 대규모 학습·추론 시스템의 성능과 효율을 높이며, 데이터·안전·아키텍처까지 포함해 AI 시스템 전체를 설계하는 수준

34. **논문 읽기·구현** — 주요 논문(Attention, BERT, GPT, ViT, Diffusion 등) PyTorch 재구현, arXiv 추적 습관
35. **대규모 학습** — 분산 학습(DDP/FSDP), 혼합 정밀도, GPU 메모리 최적화, 학습 안정화 기법
36. **추론 최적화** — 양자화, 지식 증류, 프루닝, ONNX/TensorRT, 서빙 지연·처리량·비용 튜닝
37. **데이터 중심 AI** — 데이터셋 구축·라벨링 전략, 합성 데이터, 데이터 품질 진단, 데이터 거버넌스
38. **AI 시스템 설계** — 추천/검색/LLM 서비스 아키텍처 설계, 확장성·비용·지연 트레이드오프, 장애 대응
39. **AI 안전·정렬 심화** — 레드팀, 정렬 기법(RLHF/DPO/Constitutional AI), 해석 가능성, 평가 벤치마크 설계
40. **4단계 포트폴리오·기여** — 논문 재구현 저장소 공개, 벤치마크를 포함한 최적화 사례 정리, 오픈소스 기여, 기술 발표·멘토링
