# 2장. 기본 문법

[파이썬 기초](README.md) 과정의 두 번째 장이다. 1장에서 `print()`와 `input()`으로 첫 프로그램을 만들었다면, 이 장에서는 프로그램의 뼈대가 되는 다섯 가지 문법을 익힌다.

- **변수와 자료형** — 값에 이름을 붙이고, 정수·실수·문자열·불리언이 어떻게 다른지 구분하고, 자료형을 바꾼다.
- **연산자** — 계산하고, 비교하고, 조건을 조합한다. `==`와 `is`가 어떻게 다른지 안다.
- **문자열** — 문자열의 일부를 꺼내고, 원하는 모양으로 만들고(f-string), 자르고 붙이고 바꾼다.
- **조건문** — 상황에 따라 다른 코드를 실행한다.
- **반복문** — 같은 일을 여러 번 실행한다.

이 다섯 가지만 있으면 "입력을 받아서, 계산하고, 판단하고, 반복하고, 출력하는" 프로그램을 만들 수 있다. 3장 이후의 내용(자료구조, 함수, 클래스)은 모두 이 위에 쌓인다.

## 학습 목표

이 장을 마치면 다음을 할 수 있다.

- 변수에 값을 저장하고, 값의 자료형을 `type()`으로 확인하고, 필요한 자료형으로 변환할 수 있다.
- 산술·비교·논리 연산자로 원하는 계산과 판단을 식으로 표현할 수 있다.
- 문자열을 인덱싱·슬라이싱하고, f-string으로 출력 형식을 맞추고, 주요 메서드로 가공할 수 있다.
- `if`/`elif`/`else`로 여러 경우를 나누어 처리할 수 있다.
- `for`와 `while`로 반복을 작성하고, `break`/`continue`로 반복의 흐름을 바꿀 수 있다.
- 디버거로 반복문을 한 바퀴씩 따라가며 변수 값의 변화를 확인할 수 있다.

## 2.1 변수와 자료형

### 2.1.1 변수와 할당

**변수**(variable)는 값에 붙인 **이름**이다. 이름을 붙여 두면 그 값을 나중에 다시 쓸 수 있다.

```python
>>> price = 3000
>>> count = 4
>>> price * count
12000
```

`price = 3000`은 "3000이라는 값에 `price`라는 이름을 붙여라"라는 뜻이다. 이것을 **할당**(assignment) 또는 **대입**이라고 한다.

- 표현1) price는 3000 이라는 값에 붙인 이름표다.
- 표현2) price는 메모리에 저장된 3000 이라는 값에 붙인 이름표다.
- 표현3) price는 3000 객체에 붙인 이름표다.
- 표현4) price는 3000 객체를 가리키는 이름표다.
- 표현5) price는 3000 객체의 참조를 담은 변수다.
- 표현6) price는 3000 객체를 찾아 갈 수 있는 정보를 저장한 메모리다.

`=`는 수학의 "같다"가 아니다. **오른쪽을 먼저 계산하고, 그 결과에 왼쪽 이름을 붙인다**는 뜻이다. 그래서 다음 코드가 가능하다.

```python
>>> count = 4
>>> count = count + 1
>>> count
5
```

수학이라면 `count = count + 1`은 말이 안 되지만, 파이썬은 이렇게 읽는다.

1. 오른쪽 `count + 1`을 계산한다. 지금 `count`는 4이므로 결과는 5다.
2. 그 결과 5에 `count`라는 이름을 붙인다. 이제 `count`는 5를 가리킨다.

이미 있는 이름에 다른 값을 할당하는 것을 **재할당**이라고 한다. 이전 값은 그 이름으로 더 이상 찾을 수 없다.

**만들지 않은 변수를 쓰면** 1장에서 본 `NameError`가 난다.

```python
>>> total = total + 1
Traceback (most recent call last):
  File "<python-input-0>", line 1, in <module>
    total = total + 1
            ^^^^^
NameError: name 'total' is not defined
```

`total + 1`을 계산하려는데 `total`이 아직 없다. 변수는 **먼저 할당한 다음에** 쓸 수 있다. (대화형 셸에서는 파일 이름 자리에 `<python-input-0>`처럼 표시된다. 파이썬 버전에 따라 `<stdin>`으로 보일 수도 있다.)

> **"상자"가 아니라 "이름표"**
> 변수를 "입력값을 담아 두는 상자"라고 간단히 생각할 수 있지만, 더 정확한 그림은 **값에 붙이는 이름표**다. 값은 따로 있고(객체), 변수는 그 값을 가리키는(참조) 이름일 뿐이다. 지금 단계에서는 두 그림의 차이가 드러나지 않는다. 3장 "변수와 객체"에서 `b = a`를 했을 때 무슨 일이 일어나는지 배울 때 이 차이가 중요해진다. 그때를 위해 지금부터 "이름표" 그림에 익숙해지자.

### 2.1.2 변수 이름 규칙

변수 이름은 마음대로 지을 수 있지만, **지켜야 하는 규칙**과 **지키는 것이 좋은 관례**가 있다.

**규칙 (어기면 오류)**

1. 영문자, 숫자, 밑줄(`_`)만 쓸 수 있다. (한글도 쓸 수 있지만 쓰지 않는 것이 관례다.)
2. **숫자로 시작할 수 없다.** `age2`는 되지만 `2age`는 안 된다.
3. 공백이나 `-`, `!` 같은 기호를 쓸 수 없다. `my-name`은 "my 빼기 name"으로 해석된다.
4. **대소문자를 구분한다.** `name`, `Name`, `NAME`은 서로 다른 변수다.
5. 파이썬이 문법으로 쓰는 **예약어**(keyword)는 쓸 수 없다.

```python
>>> 2age = 3
  File "<python-input-0>", line 1
    2age = 3
    ^
SyntaxError: invalid decimal literal
>>> class = 1
  File "<python-input-1>", line 1
    class = 1
          ^
SyntaxError: invalid syntax
```

예약어는 이 과정에서 대부분 배우게 된다. 미리 몇 개만 봐 두자.

```
False  None  True  and  as  break  class  continue  def  elif  else
for  from  if  import  in  is  not  or  pass  return  while  with
```

VS Code에서 예약어는 다른 색으로 표시되므로, 변수 이름이 이상한 색으로 보이면 예약어인지 의심하자.

**관례 (어겨도 실행은 되지만 지키자)**

| 관례 | 좋은 예 | 피할 예 |
|---|---|---|
| 소문자와 밑줄로 단어를 잇는다 (snake_case) | `user_name`, `total_price` | `userName`, `TotalPrice` |
| 뜻이 드러나는 이름을 쓴다 | `price`, `student_count` | `a`, `x1`, `tmp2` |
| 바뀌지 않을 값(상수)은 대문자로 쓴다 | `MAX_SCORE = 100` | |
| 파이썬 내장 함수 이름을 피한다 | `text`, `total` | `print`, `input`, `str`, `sum` |

`a`, `b`, `x` 같은 짧은 이름은 대화형 셸에서 실험할 때나 아주 짧은 반복문에서만 쓰자. 일주일 뒤의 내가 읽어도 무슨 값인지 알 수 있는 이름이 좋은 이름이다.

자바나 자바스크립트를 본 적이 있다면 `userName` 같은 카멜 표기법(camelCase)에 익숙할 것이다. 파이썬은 변수와 함수에 snake_case를 쓰는 것이 공식 스타일 가이드(PEP 8)의 관례다. (클래스 이름은 `CamelCase`를 쓰는데, 5장에서 다룬다.)

**내장 함수 이름을 덮어쓰면 생기는 일**

마지막 관례는 특히 중요하다. 다음 코드는 오류 없이 할당되지만, 그 뒤로 `print()`를 쓸 수 없게 된다.

```python
>>> print = 3
>>> print("hi")
Traceback (most recent call last):
  File "<python-input-1>", line 1, in <module>
    print("hi")
    ~~~~~^^^^^^
TypeError: 'int' object is not callable
```

`print`라는 이름이 이제 함수가 아니라 3을 가리키기 때문이다. "3을 함수처럼 호출할 수 없다"는 오류다. 대화형 셸이라면 `exit()`로 나왔다가 다시 들어가면 원래대로 돌아온다. 스크립트라면 변수 이름을 바꿔야 한다. 특히 `str`, `list`, `sum`, `max`, `input` 같은 이름은 변수 이름으로 쓰고 싶어지기 쉬우니 주의하자.

### 2.1.3 기본 자료형

값에는 종류가 있다. 이것을 **자료형**(data type, 타입)이라고 한다. 이 장에서는 가장 기본이 되는 네 가지를 다룬다.

| 자료형 | 이름 | 예 | 용도 |
|---|---|---|---|
| `int` | 정수 | `42`, `0`, `-7`, `1_000_000` | 개수, 순서, 나이처럼 소수점이 없는 수 |
| `float` | 실수(부동소수점 수) | `3.14`, `0.5`, `-2.0`, `1e6` | 키, 가격 비율처럼 소수점이 있는 수 |
| `str` | 문자열 | `"hello"`, `'파이썬'`, `""` | 글자, 문장, 텍스트 |
| `bool` | 불리언(논리값) | `True`, `False` | 참/거짓, 예/아니요 |

**정수(`int`)**

```python
>>> 42
42
>>> 1_000_000
1000000
>>> 2 ** 100
1267650600228229401496703205376
```

- 숫자 사이의 밑줄(`_`)은 읽기 쉽게 하려는 구분자일 뿐 값에는 영향이 없다. `1_000_000`은 `1000000`과 같다.
- 파이썬의 정수는 **크기 제한이 없다.** `2 ** 100`처럼 아주 큰 수도 정확하게 계산한다.

**실수(`float`)**

```python
>>> 3.14
3.14
>>> 2.0
2.0
>>> 1e6
1000000.0
```

- 소수점이 있으면 `float`다. `2`는 `int`, `2.0`은 `float`다. 값은 같지만 자료형이 다르다.
- `1e6`은 1 × 10⁶을 뜻하는 과학 표기법이다. 결과는 항상 `float`다.

실수에는 꼭 알아 둘 특징이 하나 있다.

```python
>>> 0.1 + 0.2
0.30000000000000004
```

버그가 아니다. 컴퓨터는 실수를 2진수로 저장하는데, 0.1 같은 수는 2진수로 정확히 표현할 수 없어서 아주 작은 오차가 생긴다. 파이썬만이 아니라 거의 모든 프로그래밍 언어에서 똑같다. 그래서 **실수끼리 `==`로 정확히 같은지 비교하는 것은 피한다.** (비교하는 방법은 2.2.4에서 다룬다.) 돈처럼 정확해야 하는 값은 원 단위 정수로 저장하는 것이 가장 간단한 해결책이다.

**문자열(`str`)**

따옴표로 감싼 글자들이다. 1장에서 이미 써 봤다. 2.3절 전체에서 자세히 다룬다.

```python
>>> "hello"
'hello'
>>> "42"
'42'
>>> ""
''
```

`"42"`는 숫자처럼 보이지만 따옴표가 있으므로 **문자열**이다. 대화형 셸이 결과를 `'42'`처럼 따옴표와 함께 보여 주는 것도 "이건 문자열이다"라는 표시다. `""`처럼 아무 글자도 없는 문자열은 **빈 문자열**이라고 한다.

**불리언(`bool`)**

`True`(참)와 `False`(거짓) 딱 두 값만 있다. **첫 글자는 반드시 대문자**다. `true`라고 쓰면 `NameError`가 난다.

```python
>>> True
True
>>> 3 > 5
False
```

불리언은 직접 쓰기보다 `3 > 5` 같은 **비교의 결과**로 더 자주 만난다. 2.4절의 조건문에서 핵심 역할을 한다.

### 2.1.4 `type()`으로 자료형 확인

값이나 변수의 자료형이 궁금하면 `type()`으로 확인한다.

```python
>>> type(42)
<class 'int'>
>>> type(3.14)
<class 'float'>
>>> type("42")
<class 'str'>
>>> type(True)
<class 'bool'>
>>> age = input("나이: ")
나이: 25
>>> type(age)
<class 'str'>
```

`<class 'int'>`는 "int라는 종류의 값"이라는 뜻이다. (`class`가 무엇인지는 5장에서 배운다. 지금은 "자료형"과 같은 말로 읽으면 된다.)

마지막 예를 보자. 1장에서 "`input()`은 항상 문자열을 돌려준다"고 했는데, `type()`으로 직접 확인할 수 있다. 코드가 기대와 다르게 동작할 때 `type()`으로 값의 자료형을 찍어 보는 것은 매우 유용한 습관이다.

```python
age = input("나이: ")
print(type(age))  # 디버깅용으로 잠시 넣었다가 나중에 지운다
```

### 2.1.5 자료형 변환

자료형을 바꾸고 싶으면 **자료형 이름을 함수처럼** 쓴다.

| 함수 | 하는 일 | 예 | 결과 |
|---|---|---|---|
| `int()` | 정수로 변환 | `int("42")`, `int(3.9)` | `42`, `3` |
| `float()` | 실수로 변환 | `float("3.5")`, `float(3)` | `3.5`, `3.0` |
| `str()` | 문자열로 변환 | `str(42)`, `str(3.0)` | `'42'`, `'3.0'` |
| `bool()` | 불리언으로 변환 | `bool(0)`, `bool("hi")` | `False`, `True` |

**문자열 → 숫자**: 입력값을 계산에 쓰려면 반드시 필요하다.

```python
>>> int("42") + 1
43
>>> float("3.5") * 2
7.0
>>> int("  7  ")
7
```

앞뒤 공백은 알아서 무시해 준다. 하지만 숫자로 읽을 수 없는 문자열은 `ValueError`가 난다.

```python
>>> int("abc")
ValueError: invalid literal for int() with base 10: 'abc'
>>> int("3.14")
ValueError: invalid literal for int() with base 10: '3.14'
```

(이 교재에서는 짧은 오류는 트레이스백의 마지막 줄만 적는다. 실제로는 그 위에 `Traceback ...`과 위치가 함께 출력된다.)

두 번째 예가 함정이다. `"3.14"`는 숫자처럼 보이지만 `int()`는 정수 모양의 문자열만 받는다. 소수점이 있는 문자열을 정수로 만들고 싶으면 `float()`을 거친다.

```python
>>> int(float("3.14"))
3
```

**실수 → 정수**: 소수점 아래를 **버린다.** 반올림이 아니다.

```python
>>> int(3.9)
3
>>> int(-3.9)
-3
>>> round(3.9)
4
>>> round(3.14159, 2)
3.14
```

반올림이 필요하면 `round()`를 쓴다. `round(값, 자릿수)`처럼 소수점 아래 몇 자리까지 남길지 정할 수도 있다.

**숫자 → 문자열**: 문자열과 이어 붙일 때 필요하다.

```python
>>> "나이: " + 25
TypeError: can only concatenate str (not "int") to str
>>> "나이: " + str(25)
'나이: 25'
```

1장에서 본 `TypeError`와 같은 오류다. 문자열과 숫자는 `+`로 이을 수 없으므로 `str()`로 숫자를 문자열로 바꾼다. 다만 실제로는 이 방법보다 2.3.4에서 배울 **f-string**을 훨씬 많이 쓴다.

**자동 변환**: 정수와 실수를 섞어 계산하면 결과는 자동으로 실수가 된다. 정보를 잃지 않는 쪽으로 바뀌는 것이다.

```python
>>> 3 + 0.5
3.5
>>> type(3 + 3.0)
<class 'float'>
```

`bool()` 변환은 2.4.5의 "참·거짓으로 평가되는 값"에서 자세히 다룬다.

### 2.1.6 `None`: 값이 없음

`None`은 "**값이 없다**"를 나타내는 특별한 값이다. 자료형은 `NoneType`이고, 세상에 `None`은 딱 하나뿐이다. `True`/`False`처럼 첫 글자는 대문자다.

```python
>>> result = None
>>> print(result)
None
>>> type(result)
<class 'NoneType'>
>>> result
>>>
```

마지막 줄을 보자. 대화형 셸은 계산 결과를 보여 주지만, 결과가 `None`이면 **아무것도 보여 주지 않는다.** `print()`로 출력해야 `None`이라는 글자가 보인다.

`None`은 다음과 같은 상황에서 쓴다.

- **아직 정해지지 않은 값**: `winner = None`으로 시작했다가, 나중에 우승자가 정해지면 할당한다.
- **결과가 없음**: 무언가를 찾았는데 없을 때 "없다"는 뜻으로 돌려준다.

`0`이나 빈 문자열 `""`과 헷갈리지 말자. `0`은 "값이 0이다", `""`는 "글자가 하나도 없는 문자열이다"라는 뜻이고, `None`은 "**값 자체가 없다**"는 뜻이다. 예를 들어 시험 점수가 `0`이면 시험을 봤는데 0점이라는 뜻이고, `None`이면 아직 시험을 안 봤다는 뜻으로 구분할 수 있다.

변수가 `None`인지 확인하는 방법은 2.2.8에서 다룬다. 4장 "함수"에서는 `return`이 없는 함수가 `None`을 돌려준다는 것을 배운다.

## 2.2 연산자

**연산자**(operator)는 값을 계산하거나 비교하는 기호다. `+`, `>`, `and` 같은 것들이다. 연산자로 연결한 `price * count` 같은 덩어리를 **식**(expression, 표현식)이라고 하며, 식은 계산되어 하나의 값이 된다.

### 2.2.1 산술 연산자

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `7 + 2` | `9` |
| `-` | 빼기 | `7 - 2` | `5` |
| `*` | 곱하기 | `7 * 2` | `14` |
| `/` | 나누기 | `7 / 2` | `3.5` |
| `//` | 정수 나눗셈(몫) | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `7 ** 2` | `49` |

**`/`는 항상 실수를 돌려준다.** 나누어떨어져도 그렇다.

```python
>>> 6 / 2
3.0
>>> 7 / 2
3.5
```

실습 2-1에서 `type(10 / 2)`가 `float`였던 이유다. 결과를 정수로 쓰고 싶으면 `//`를 쓴다.

**`//`(몫)와 `%`(나머지)** 는 함께 쓰는 경우가 많다. 초등학교에서 배운 "7 나누기 2는 몫이 3, 나머지가 1"이다.

```python
>>> 7 // 2
3
>>> 7 % 2
1
```

이 두 연산자는 생각보다 자주 쓰인다.

| 하고 싶은 일 | 식 | 설명 |
|---|---|---|
| 짝수인지 확인 | `n % 2 == 0` | 2로 나눈 나머지가 0이면 짝수 |
| 배수인지 확인 | `n % 3 == 0` | 3으로 나눈 나머지가 0이면 3의 배수 |
| 마지막 자리 숫자 | `n % 10` | `1234 % 10`은 `4` |
| 마지막 자리 떼기 | `n // 10` | `1234 // 10`은 `123` |
| 단위 변환 | `총초 // 60`, `총초 % 60` | 분과 남은 초 |

예를 들어 3661초를 시·분·초로 바꾸면 다음과 같다.

```python
>>> seconds = 3661
>>> seconds // 3600          # 시
1
>>> seconds % 3600 // 60     # 시간을 빼고 남은 초를 60으로 나눈 몫 = 분
1
>>> seconds % 60             # 초
1
```

> **음수의 몫과 나머지**
> `-7 // 2`는 `-3`이 아니라 `-4`다. `//`는 0 쪽이 아니라 **더 작은 쪽으로** 내림하기 때문이다. 그래서 `-7 % 2`는 `1`이 된다(`-4 × 2 + 1 = -7`). 다른 언어(자바, C)와 결과가 다르므로, 음수를 나눌 일이 있으면 대화형 셸에서 먼저 확인하자. 대부분의 실습에서는 음수를 나눌 일이 없다.

**0으로 나누면** 오류가 난다.

```python
>>> 10 / 0
ZeroDivisionError: division by zero
```

`//`와 `%`도 마찬가지다. 사용자가 입력한 값으로 나눌 때는 0이 들어올 수 있다는 것을 기억하자. (2.4절의 조건문으로 미리 막을 수 있다.)

**문자열에 쓰는 `+`와 `*`**

`+`와 `*`는 문자열에도 쓸 수 있다. 뜻이 조금 다르다.

```python
>>> "안녕" + "하세요"     # 이어 붙이기
'안녕하세요'
>>> "=" * 20             # 반복하기
'===================='
>>> "ab" * 3
'ababab'
```

`"=" * 20`은 출력에서 구분선을 만들 때 자주 쓴다.

### 2.2.2 복합 할당 연산자

`count = count + 1`처럼 "변수의 현재 값에 무언가를 계산해서 다시 저장하는" 일은 아주 흔하다. 그래서 줄여 쓰는 방법이 있다.

| 복합 할당 | 같은 뜻 |
|---|---|
| `x += 3` | `x = x + 3` |
| `x -= 3` | `x = x - 3` |
| `x *= 3` | `x = x * 3` |
| `x /= 3` | `x = x / 3` |
| `x //= 3` | `x = x // 3` |
| `x %= 3` | `x = x % 3` |

```python
>>> score = 0
>>> score += 10
>>> score += 5
>>> score
15
>>> message = "안녕"
>>> message += "하세요"
>>> message
'안녕하세요'
```

다른 언어의 `x++`(1 증가)는 파이썬에 **없다.** `x += 1`로 쓴다.

```python
>>> x = 3
>>> x++
SyntaxError: invalid syntax
```

### 2.2.3 비교 연산자

두 값을 비교해서 결과를 **불리언**(`True`/`False`)으로 돌려준다.

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---|
| `==` | 같다 | `3 == 3` | `True` |
| `!=` | 다르다 | `3 != 3` | `False` |
| `<` | 작다 | `3 < 5` | `True` |
| `>` | 크다 | `3 > 5` | `False` |
| `<=` | 작거나 같다 | `5 <= 5` | `True` |
| `>=` | 크거나 같다 | `3 >= 5` | `False` |

**`=`와 `==`를 혼동하지 말자.** `=`는 할당, `==`는 비교다. 조건문에서 `==` 대신 `=`를 쓰면 파이썬이 바로 알려 준다.

```python
x = 5
if x = 5:
    print(x)
```

```
    if x = 5:
       ^^^^^
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

"`==`를 쓰려던 것 아니냐"고 제안까지 해 준다. (`:=`는 이 과정에서 다루지 않는다.)

**연속 비교**: 수학처럼 비교를 이어 쓸 수 있다.

```python
>>> age = 15
>>> 13 <= age < 20      # 13 이상 20 미만인가?
True
```

`13 <= age and age < 20`과 같은 뜻이다. 범위를 확인할 때 읽기 쉽다.

**자료형이 다른 값의 비교**

```python
>>> 3 == 3.0
True
>>> 3 == "3"
False
```

정수 `3`과 실수 `3.0`은 같은 수이므로 `True`다. 하지만 정수 `3`과 문자열 `"3"`은 **서로 다른 종류의 값**이므로 `False`다. `input()`으로 받은 값을 숫자와 비교하는데 항상 `False`가 나온다면 이것이 원인이다.

**문자열의 크기 비교**: 사전 순서로 비교한다.

```python
>>> "apple" < "banana"
True
>>> "Z" < "a"
True
>>> "10" < "9"
True
```

두 번째와 세 번째 결과가 이상해 보인다. 문자열은 **글자 하나하나의 코드값**을 앞에서부터 비교하는데, 대문자가 소문자보다 코드값이 작고, `"1"`이 `"9"`보다 작기 때문이다. `"10" < "9"`가 `True`라는 것은 **숫자를 문자열인 채로 비교하면 안 된다**는 뜻이다. 비교하기 전에 `int()`로 바꾸자.

### 2.2.4 실수 비교

2.1.3에서 본 실수의 오차 때문에 다음 결과가 나온다.

```python
>>> 0.1 + 0.2 == 0.3
False
```

실수가 "거의 같은지" 확인하려면 차이가 아주 작은지 본다. `abs()`는 절댓값을 돌려주는 내장 함수다.

```python
>>> abs((0.1 + 0.2) - 0.3) < 1e-9
True
```

`1e-9`는 0.000000001이다. "두 값의 차이가 10억분의 1보다 작으면 같다고 보자"는 뜻이다. 4장에서 배울 `math` 모듈의 `math.isclose()`를 쓰면 더 간단하다. 지금은 "실수는 `==`로 비교하지 않는다"만 기억하자.

### 2.2.5 논리 연산자

여러 조건을 조합할 때 쓴다.

| 연산자 | 의미 | 결과가 `True`인 경우 |
|---|---|---|
| `and` | 그리고 | 양쪽이 **모두** `True`일 때 |
| `or` | 또는 | 어느 한쪽이라도 `True`일 때 |
| `not` | 아니다 | 뒤의 값이 `False`일 때 (뒤집기) |

```python
>>> age = 25
>>> has_ticket = True
>>> age >= 19 and has_ticket
True
>>> age < 13 or age >= 65
False
>>> not has_ticket
False
```

결과를 표로 정리하면 다음과 같다.

| A | B | `A and B` | `A or B` | `not A` |
|---|---|---|---|---|
| `True` | `True` | `True` | `True` | `False` |
| `True` | `False` | `False` | `True` | `False` |
| `False` | `True` | `False` | `True` | `True` |
| `False` | `False` | `False` | `False` | `True` |

다른 언어의 `&&`, `||`, `!` 대신 파이썬은 영어 단어 `and`, `or`, `not`을 쓴다.

**단락 평가**: `and`는 왼쪽이 `False`면 오른쪽을 **보지도 않는다.** 이미 결과가 `False`로 정해졌기 때문이다. `or`는 왼쪽이 `True`면 오른쪽을 보지 않는다. 이 성질을 이용해 오류를 피할 수 있다.

```python
>>> count = 0
>>> count != 0 and 100 / count > 10
False
```

`count != 0`이 `False`이므로 `100 / count`는 실행되지 않는다. 순서를 바꾸면 `ZeroDivisionError`가 난다. **안전 검사를 먼저** 쓰자.

### 2.2.6 연산자 우선순위

여러 연산자가 섞이면 수학과 마찬가지로 정해진 순서대로 계산한다.

| 순위 | 연산자 | 설명 |
|---|---|---|
| 1 (먼저) | `( )` | 괄호 |
| 2 | `**` | 거듭제곱 |
| 3 | `-x` | 부호(음수) |
| 4 | `*`, `/`, `//`, `%` | 곱셈·나눗셈 |
| 5 | `+`, `-` | 덧셈·뺄셈 |
| 6 | `==`, `!=`, `<`, `>`, `<=`, `>=`, `in`, `not in`, `is`, `is not` | 비교 |
| 7 | `not` | 논리 부정 |
| 8 | `and` | 논리곱 |
| 9 (나중) | `or` | 논리합 |

```python
>>> 1 + 2 * 3
7
>>> (1 + 2) * 3
9
>>> -2 ** 2
-4
```

세 번째가 함정이다. `**`가 부호보다 먼저이므로 `-(2 ** 2)`로 계산된다. `(-2) ** 2`를 원하면 괄호를 써야 한다.

산술 → 비교 → 논리 순서라는 큰 흐름만 기억하면 대부분 의도대로 동작한다. 그래서 `age >= 19 and has_ticket`은 비교가 먼저 계산되고 나서 `and`가 계산된다.

**가장 좋은 규칙은 "헷갈리면 괄호"다.** 괄호는 계산 순서를 바꿀 뿐 아니라, 코드를 읽는 사람에게 의도를 알려 준다.

```python
# 의도는 같지만 아래쪽이 훨씬 읽기 쉽다
is_discount = age < 13 or age >= 65 and is_member
is_discount = age < 13 or ((age >= 65) and is_member)
```

`A or B and C`는 연산자 우선순위에 따라 `A or (B and C)`로 계산된다.

### 2.2.7 멤버십 연산자: `in`, `not in`

`in`은 "**안에 들어 있는가**"를 확인한다. 문자열에 쓰면 부분 문자열이 들어 있는지 본다.

```python
>>> "py" in "python"
True
>>> "Py" in "python"
False
>>> "@" in "user@example.com"
True
>>> "z" not in "python"
True
```

대소문자를 구분하므로 `"Py"`는 `"python"` 안에 없다. `not in`은 `in`의 반대다. `not ("z" in "python")`보다 `"z" not in "python"`이 읽기 쉬우므로 이쪽을 쓴다.

`in`은 3장에서 배울 리스트, 딕셔너리, 집합에서도 똑같이 쓴다. 지금은 문자열로 익혀 두자.

### 2.2.8 `==`와 `is`의 차이, `is None`

파이썬에는 "같은가"를 묻는 연산자가 두 개 있다.

- `==` — 두 값의 **내용**이 같은가?
- `is` — 두 이름이 **바로 그 하나의 값**(같은 객체)을 가리키는가?

비유하면 `==`는 "두 책의 내용이 같은가", `is`는 "두 사람이 들고 있는 것이 **같은 한 권**의 책인가"를 묻는 것이다. 같은 내용으로 인쇄된 두 권의 책은 `==`로는 같지만 `is`로는 다르다.

이 차이가 실제로 문제 되는 경우는 3장 "변수와 객체"에서 `id()`와 함께 자세히 다룬다. 지금 기억할 규칙은 두 가지뿐이다.

1. **값을 비교할 때는 `==`를 쓴다.** 숫자, 문자열 비교는 모두 `==`다.
2. **`None`인지 확인할 때만 `is`를 쓴다.**

```python
>>> result = None
>>> result is None
True
>>> result is not None
False
```

`None`은 세상에 하나뿐인 값이므로, "이 변수가 바로 그 `None`을 가리키는가"를 `is`로 묻는 것이 정확하다. `result == None`도 대부분 같은 결과를 내지만, 파이썬 스타일 가이드(PEP 8)는 `is None`을 쓰도록 정하고 있다. AI가 만든 코드에서도 거의 항상 `is None`으로 쓰여 있을 것이다.

반대로 **숫자나 문자열을 `is`로 비교하면 안 된다.**

```python
>>> x = 1000
>>> x == 1000
True
>>> x is 1000
<python-input-2>:1: SyntaxWarning: "is" with 'int' literal. Did you mean "=="?
False
```

값은 분명히 같은데 `is`의 결과는 `False`다. 같은 코드라도 실행 방식에 따라 `True`가 나오기도 한다. 결과가 파이썬 내부 사정에 따라 달라지기 때문에, 파이썬이 직접 "`==`를 쓰려던 것 아니냐"고 경고한다. VS Code에서도 Ruff가 이 줄에 밑줄을 긋는다. 경고가 보이면 `==`로 고치자.

### 실습 2-2. 연산자

**1) 대화형 셸에서 예상하고 확인하기**

```python
>>> 17 // 5
>>> 17 % 5
>>> 2 ** 3 * 2
>>> 10 - 2 - 3
>>> 5 > 3 and 3 > 1
>>> not 5 > 3
>>> "a" in "banana"
>>> "ana" in "banana"
>>> 7 == 7.0
>>> "7" == 7
```

**2) `time_convert.py` — 초를 시·분·초로**

초를 입력받아 시·분·초로 바꿔 출력한다.

```
초를 입력하세요: 7384
2 시간 3 분 4 초
```

**3) `even_odd.py` — 짝수·홀수 판별 (조건문 없이)**

정수를 입력받아 짝수인지, 3의 배수인지, 10보다 큰지를 각각 `True`/`False`로 출력한다. 조건문은 아직 배우지 않았으므로 비교 연산자의 결과를 그대로 출력한다.

```
정수: 12
짝수인가? True
3의 배수인가? True
10보다 큰가? True
```

**4) `digits.py` — 자릿수 분리**

세 자리 정수를 입력받아 백의 자리, 십의 자리, 일의 자리를 각각 출력한다. 문자열로 다루지 말고 `//`와 `%`만 사용한다.

```
세 자리 정수: 472
백의 자리: 4
십의 자리: 7
일의 자리: 2
```

## 2.3 문자열

문자열은 프로그램이 다루는 데이터 중 가장 흔한 것이다. 사용자 입력, 파일 내용, 웹 응답, LLM의 대답까지 모두 문자열이다. 이 과정 이후 LLM API를 다룰 때도 결국 문자열을 만들고 자르고 붙이는 일을 계속하게 된다.

### 2.3.1 문자열 만들기와 길이

큰따옴표나 작은따옴표로 감싼다. 1장에서 본 대로 Ruff가 큰따옴표로 통일해 주므로, 이 교재는 큰따옴표를 쓴다.

```python
>>> s = "Python"
>>> len(s)
6
>>> len("안녕하세요")
5
>>> len("")
0
```

`len()`은 문자열의 **길이**(글자 수)를 돌려주는 내장 함수다. 한글도 한 글자를 1로 센다. 공백과 문장 부호도 한 글자다. (`len()`은 3장의 리스트 등에도 똑같이 쓴다. 내장 함수는 4장에서 정리한다.)

### 2.3.2 인덱싱

문자열은 글자가 **순서대로** 늘어선 것이다. 각 글자에는 위치 번호가 있고, 이것을 **인덱스**(index)라고 한다. 대괄호 `[ ]`에 인덱스를 넣어 글자 하나를 꺼낸다.

```
 글자:    P    y    t    h    o    n
 인덱스:  0    1    2    3    4    5
 음수:   -6   -5   -4   -3   -2   -1
```

```python
>>> s = "Python"
>>> s[0]
'P'
>>> s[3]
'h'
>>> s[-1]
'n'
>>> s[-2]
'o'
```

- 인덱스는 **0부터** 시작한다. 첫 글자는 `s[0]`, 여섯 글자짜리 문자열의 마지막 글자는 `s[5]`다.
- **음수 인덱스**는 뒤에서부터 센다. `s[-1]`은 항상 마지막 글자다. 길이를 몰라도 마지막 글자를 꺼낼 수 있어 편리하다.

범위를 벗어난 인덱스는 `IndexError`가 난다.

```python
>>> s[10]
IndexError: string index out of range
```

**문자열은 바꿀 수 없다**

인덱스로 글자를 꺼낼 수는 있지만, 그 자리의 글자를 **바꿀 수는 없다.**

```python
>>> s[0] = "J"
TypeError: 'str' object does not support item assignment
```

문자열은 한 번 만들면 내용을 바꿀 수 없는 **불변**(immutable) 값이다. "Jython"을 원하면 바꾸는 것이 아니라 **새 문자열을 만들어야** 한다.

```python
>>> s = "J" + s[1:]
>>> s
'Jython'
```

`s[1:]`은 바로 다음에 배울 슬라이싱이다. 그리고 마지막 줄의 `s = ...`는 원래 문자열을 고친 것이 아니라, 새로 만든 문자열에 `s`라는 이름표를 옮겨 붙인 것이다. 불변과 가변의 차이는 3장 "변수와 객체"에서 정식으로 다룬다.

### 2.3.3 슬라이싱

**슬라이싱**(slicing)은 문자열의 **일부분**을 잘라 낸다. `s[시작:끝]` 형태로 쓰며, **시작 인덱스는 포함하고 끝 인덱스는 포함하지 않는다.**

```python
>>> s = "Python"
>>> s[0:2]
'Py'
>>> s[2:5]
'tho'
```

`s[0:2]`는 인덱스 0, 1까지다. 2는 포함하지 않는다. 헷갈리면 인덱스를 **글자 사이의 칸막이**로 생각하면 쉽다.

```
   | P | y | t | h | o | n |
   0   1   2   3   4   5   6
```

`s[2:5]`는 칸막이 2와 5 사이에 있는 글자, 즉 `tho`다. 이렇게 보면 `s[a:b]`의 길이가 `b - a`라는 것도 알 수 있다.

**시작이나 끝을 생략**하면 처음부터, 또는 끝까지라는 뜻이다.

```python
>>> s[:3]       # 처음부터 3 앞까지 = 앞 3글자
'Pyt'
>>> s[3:]       # 3부터 끝까지
'hon'
>>> s[-3:]      # 뒤에서 3번째부터 끝까지 = 뒤 3글자
'hon'
>>> s[:]        # 전체
'Python'
```

`s[:n]`(앞 n글자), `s[-n:]`(뒤 n글자), `s[1:]`(첫 글자 빼고)는 자주 쓰는 모양이니 외워 두자.

**간격(step)**: 세 번째 숫자는 몇 칸씩 건너뛸지 정한다.

```python
>>> s[::2]      # 처음부터 끝까지 2칸씩
'Pto'
>>> s[::-1]     # 뒤에서부터 1칸씩 = 뒤집기
'nohtyP'
```

`s[::-1]`은 문자열을 뒤집는 관용구로 널리 쓰인다.

**슬라이싱은 범위를 벗어나도 오류가 나지 않는다.** 인덱싱과 다른 점이다.

```python
>>> s[1:100]
'ython'
>>> s[10:]
''
```

있는 만큼만 잘라 주고, 하나도 없으면 빈 문자열을 돌려준다.

### 2.3.4 f-string 포매팅

출력 문장 안에 변수 값을 넣는 방법은 여러 가지가 있다. 지금까지 배운 두 가지와 비교해 보자.

```python
name = "홍길동"
age = 25

print("이름:", name, "나이:", age)              # ① 쉼표로 나열 — 사이에 공백이 자동으로 들어간다
print("이름: " + name + ", 나이: " + str(age))  # ② + 로 이어 붙이기 — 숫자는 str()로 바꿔야 한다
print(f"이름: {name}, 나이: {age}")             # ③ f-string
```

```
이름: 홍길동 나이: 25
이름: 홍길동, 나이: 25
이름: 홍길동, 나이: 25
```

①은 공백을 마음대로 조절할 수 없고, ②는 `+`와 따옴표, `str()`이 많아서 읽기 어렵고 틀리기 쉽다. ③ **f-string**은 문자열 앞에 `f`를 붙이고, 값이 들어갈 자리에 `{변수}`를 적는다. 완성될 문장의 모양이 그대로 보이므로 가장 읽기 쉽다. 숫자도 `str()` 없이 바로 넣을 수 있다. 1장 실습에서 "공백 없이 붙이는 방법은 2장에서 배운다"고 했던 것이 바로 이것이다. **앞으로 출력 문장은 f-string으로 만든다.**

**중괄호 안에는 식을 쓸 수 있다**

```python
>>> price = 3000
>>> count = 4
>>> f"총액: {price * count}원"
'총액: 12000원'
>>> f"내년 나이: {age + 1}"
'내년 나이: 26'
>>> f"이름 길이: {len(name)}"
'이름 길이: 3'
```

**형식 지정**: 중괄호 안에서 콜론(`:`) 뒤에 형식을 적으면 숫자를 원하는 모양으로 출력할 수 있다.

| 형식 | 의미 | 예 | 결과 |
|---|---|---|---|
| `:.2f` | 소수점 아래 2자리 | `f"{3.14159:.2f}"` | `3.14` |
| `:,` | 천 단위 쉼표 | `f"{1234567:,}"` | `1,234,567` |
| `:,.2f` | 쉼표 + 소수점 2자리 | `f"{1234567.891:,.2f}"` | `1,234,567.89` |
| `:.1%` | 백분율(×100), 소수점 1자리 | `f"{0.256:.1%}"` | `25.6%` |
| `:05d` | 정수를 5자리로, 빈자리는 0 | `f"{7:05d}"` | `00007` |
| `:>8` | 8칸 오른쪽 정렬 | `f"[{'hi':>8}]"` | `[      hi]` |
| `:<8` | 8칸 왼쪽 정렬 | `f"[{'hi':<8}]"` | `[hi      ]` |
| `:^8` | 8칸 가운데 정렬 | `f"[{'hi':^8}]"` | `[   hi   ]` |

(표의 `'hi'`는 f-string의 큰따옴표 안에서 문자열을 바로 쓰려고 작은따옴표를 쓴 것이다. 실제로는 대부분 변수를 넣는다.)

```python
>>> average = 87.66666
>>> f"평균: {average:.1f}점"
'평균: 87.7점'
>>> salary = 3500000
>>> f"월급: {salary:,}원"
'월급: 3,500,000원'
```

**정렬로 표 만들기**

```python
# receipt.py
item1 = "아메리카노"
price1 = 4500
item2 = "케이크"
price2 = 12000

print(f"{'품목':<10}{'가격':>10}")
print("-" * 20)
print(f"{item1:<10}{price1:>10,}")
print(f"{item2:<10}{price2:>10,}")
```

```
품목                가격
--------------------
아메리카노          4,500
케이크           12,000
```

숫자 열(가격)은 오른쪽 정렬이 잘 맞는다. 그런데 품목 열을 보면 줄이 살짝 어긋나 보인다. f-string은 **글자 수**로 칸을 세는데, 터미널에서 한글은 영문보다 **폭이 두 배**로 보이기 때문이다. 영문과 숫자만 있으면 정확히 맞는다. 한글까지 정확히 맞추는 것은 이 과정의 범위를 넘으므로, 한글이 섞인 표는 "대략 맞는" 것으로 만족하자.

**디버깅용 `=`**

중괄호 안에서 변수 뒤에 `=`를 붙이면 "이름=값" 형태로 보여 준다. 디버깅할 때 아주 편하다.

```python
>>> x = 3
>>> f"{x=}"
'x=3'
>>> f"{x * 2=}"
'x * 2=6'
```

`print(f"{price=}, {count=}")`처럼 넣어 두면 어떤 변수의 값인지 헷갈리지 않는다.

**중괄호 자체를 출력하려면** 두 번 쓴다: `f"{{중괄호}}"` → `{중괄호}`.

### 2.3.5 문자열 메서드

**메서드**(method)는 특정 자료형의 값에 딸린 함수다. `값.메서드이름()` 형태로 점(`.`)을 찍어 호출한다.

```python
>>> name = "python"
>>> name.upper()
'PYTHON'
```

`upper()`는 "이 문자열을 대문자로 바꾼 것"을 돌려주는 문자열 메서드다. `print()`나 `len()`은 `print(name)`처럼 값을 괄호 안에 넣는 반면, 메서드는 값 뒤에 점을 찍는다는 차이가 있다. (메서드가 어떻게 만들어지는지는 5장 "클래스"에서 배운다.)

**가장 중요한 점: 문자열 메서드는 원래 문자열을 바꾸지 않는다.** 문자열은 불변이므로, 메서드는 항상 **새 문자열을 만들어서 돌려준다.**

```python
>>> name = "python"
>>> name.upper()
'PYTHON'
>>> name
'python'
```

`name`은 그대로다. 결과를 쓰려면 **변수에 다시 할당**해야 한다.

```python
>>> name = name.upper()
>>> name
'PYTHON'
```

"메서드를 호출했는데 아무것도 안 바뀌었어요"라는 실수의 대부분이 이것이다.

**대소문자 바꾸기**

```python
>>> "Hello".upper()
'HELLO'
>>> "Hello".lower()
'hello'
```

사용자 입력을 비교할 때 유용하다. `answer.lower() == "yes"`라고 쓰면 `Yes`, `YES`, `yes`를 모두 같은 답으로 처리할 수 있다.

**`strip()` — 앞뒤 공백 제거**

```python
>>> text = "   hello world   "
>>> text.strip()
'hello world'
>>> text.lstrip()       # 왼쪽(앞)만
'hello world   '
>>> text.rstrip()       # 오른쪽(뒤)만
'   hello world'
```

가운데 공백은 그대로 둔다. 사용자가 입력할 때 실수로 공백을 넣는 경우가 많으므로 `input()` 결과에 `strip()`을 붙이는 것은 좋은 습관이다.

```python
name = input("이름: ").strip()
```

`input()`이 돌려준 문자열에 바로 `.strip()`을 붙였다. 이처럼 메서드의 결과에 다시 메서드를 이어 붙이는 것을 **메서드 체이닝**이라고 한다. `input().strip().lower()`처럼 여러 개를 이을 수도 있다.

공백이 아닌 글자를 지정할 수도 있다: `"***hi***".strip("*")` → `'hi'`.

**`replace()` — 바꾸기**

```python
>>> "banana".replace("a", "o")
'bonono'
>>> "banana".replace("a", "o", 1)     # 앞에서부터 1개만
'bonana'
>>> "010-1234-5678".replace("-", "")   # 빈 문자열로 바꾸기 = 지우기
'01012345678'
```

**`find()` — 위치 찾기**

```python
>>> "hello".find("l")
2
>>> "hello".find("z")
-1
>>> email = "user@example.com"
>>> email.find("@")
4
```

처음 나오는 위치의 인덱스를 돌려준다. **찾지 못하면 `-1`** 을 돌려준다. 비슷한 `index()` 메서드는 찾지 못하면 `ValueError`를 낸다는 점만 다르다.

`find()`와 슬라이싱을 함께 쓰면 문자열을 원하는 위치에서 자를 수 있다.

```python
>>> at = email.find("@")
>>> email[:at]
'user'
>>> email[at + 1:]
'example.com'
```

단순히 "들어 있는가"만 알고 싶으면 `find()`보다 `in`(2.2.7)이 읽기 쉽다.

**`split()` — 나누기**

문자열을 구분자를 기준으로 **여러 조각으로 나눈다.**

```python
>>> "2026-10-29".split("-")
['2026', '10', '29']
>>> "사과,배,포도".split(",")
['사과', '배', '포도']
>>> "hello   python  world".split()
['hello', 'python', 'world']
```

구분자를 생략하면 공백(여러 칸이어도, 탭이나 줄바꿈이어도)을 기준으로 나눈다. 단어를 나눌 때 편리하다.

> **미리 보기: 리스트**
> `split()`의 결과 `['2026', '10', '29']`처럼 대괄호로 감싸 여러 값을 순서대로 모아 둔 것을 **리스트**(list)라고 한다. 리스트는 3장의 첫 주제다. 지금은 "여러 값을 한 줄로 모아 둔 것"이고, 문자열처럼 `[0]`, `[1]`로 하나씩 꺼낼 수 있다는 것만 알면 충분하다.
> ```python
> >>> parts = "2026-10-29".split("-")
> >>> parts[0]
> '2026'
> >>> int(parts[1]) + 1
> 11
> ```
> 나눈 조각도 문자열이므로 숫자로 쓰려면 `int()`로 바꿔야 한다.

**`join()` — 잇기**

`split()`의 반대다. 여러 문자열을 **사이에 구분자를 넣어** 하나로 잇는다. 모양이 조금 특이한데, **구분자가 앞에 오고** 이을 것들이 괄호 안에 들어간다.

```python
>>> "-".join(["2026", "10", "29"])
'2026-10-29'
>>> ", ".join(["사과", "배", "포도"])
'사과, 배, 포도'
>>> "".join(["a", "b", "c"])
'abc'
```

"`-`로 이어라, 이것들을"이라고 읽으면 된다. `split()`과 `join()`을 함께 쓰면 구분자를 바꿀 수 있다.

```python
>>> "/".join("2026-10-29".split("-"))
'2026/10/29'
```

(이 경우는 `replace("-", "/")`가 더 간단하다. 두 방법이 있다는 것을 보여 주려는 예다.)

**그 밖에 자주 쓰는 메서드**

| 메서드 | 하는 일 | 예 | 결과 |
|---|---|---|---|
| `startswith()` | 이것으로 시작하는가 | `"hello.py".startswith("he")` | `True` |
| `endswith()` | 이것으로 끝나는가 | `"hello.py".endswith(".py")` | `True` |
| `count()` | 몇 번 나오는가 | `"banana".count("a")` | `3` |
| `isdigit()` | 모두 숫자인가 | `"123".isdigit()` | `True` |

`isdigit()`는 `int()`로 바꾸기 전에 숫자인지 확인할 때 쓸 수 있다. (`"-5"`나 `"3.14"`는 `False`가 나온다는 한계가 있다. 더 확실한 방법은 6장 "예외"에서 배운다.)

**메서드를 모두 외울 필요는 없다.** 대화형 셸에서 `dir("")`을 입력하면 문자열 메서드 목록이, `help(str.split)`을 입력하면 설명이 나온다. (`help()` 화면은 `q`를 눌러 빠져나온다.) VS Code에서는 문자열 변수 뒤에 점을 찍으면 메서드 목록이 자동으로 뜬다. 필요할 때 찾아 쓰는 법은 4장 "내장 함수 활용"에서 정리한다.

### 2.3.6 이스케이프 문자

문자열 안에서 **역슬래시**(`\`, Windows 키보드에서는 `₩`로 보이기도 한다)는 특별한 뜻을 가진다. 역슬래시와 다음 글자를 합쳐 **이스케이프 문자**(escape sequence)라고 하며, 직접 입력하기 어려운 글자를 나타낸다.

| 이스케이프 | 의미 |
|---|---|
| `\n` | 줄바꿈 (new line) |
| `\t` | 탭 |
| `\\` | 역슬래시 자체 |
| `\"` | 큰따옴표 (큰따옴표 문자열 안에서) |
| `\'` | 작은따옴표 (작은따옴표 문자열 안에서) |

```python
print("첫째 줄\n둘째 줄")
print("이름\t나이")
print("그가 \"안녕\"이라고 말했다")
```

```
첫째 줄
둘째 줄
이름	나이
그가 "안녕"이라고 말했다
```

`\n`은 정말 자주 쓴다. 2글자처럼 보이지만 **줄바꿈 문자 1개**다. `len("\n")`은 `1`이다.

**Windows 경로 주의**

Windows 경로에는 역슬래시가 들어간다. 그대로 쓰면 의도치 않은 이스케이프가 될 수 있다.

```python
print("C:\new\temp")
```

```
C:
ew	emp
```

`\n`이 줄바꿈으로, `\t`가 탭으로 바뀌어 버렸다. 해결 방법은 세 가지다.

```python
print("C:\\new\\temp")    # ① 역슬래시를 두 번 쓴다
print(r"C:\new\temp")     # ② 문자열 앞에 r을 붙인다 (raw string: 이스케이프를 처리하지 않음)
print("C:/new/temp")      # ③ 슬래시를 쓴다 (Windows에서도 대부분 동작한다)
```

②의 `r"..."`을 **raw 문자열**이라고 한다. 파일 경로는 7장에서 `pathlib`으로 더 안전하게 다루는 법을 배운다.

> `"\d"`처럼 뜻이 없는 이스케이프를 쓰면 `SyntaxWarning: invalid escape sequence '\d'` 경고가 나온다. 경고가 보이면 역슬래시를 두 번 쓰거나 `r`을 붙이자.

### 2.3.7 여러 줄 문자열

따옴표를 **세 개**(`"""` 또는 `'''`) 쓰면 여러 줄에 걸친 문자열을 만들 수 있다. 입력한 줄바꿈이 그대로 문자열에 들어간다.

```python
menu = """=== 메뉴 ===
1. 새 게임
2. 불러오기
3. 종료"""
print(menu)
```

```
=== 메뉴 ===
1. 새 게임
2. 불러오기
3. 종료
```

`\n`을 여러 번 쓰는 것보다 결과 모양이 코드에 그대로 보여서 읽기 쉽다. 안내문, 메뉴, 그리고 나중에 LLM에 보낼 **긴 프롬프트**를 만들 때 많이 쓴다. f-string과 합쳐 `f"""..."""`로 쓸 수도 있다.

```python
name = "홍길동"
prompt = f"""다음 사용자에게 인사말을 작성해 줘.
- 이름: {name}
- 말투: 친근하게"""
print(prompt)
```

여는 `"""` 바로 뒤에서 줄을 바꾸면 문자열이 줄바꿈 문자로 시작한다는 점만 주의하자. 4장에서 배울 함수 설명(독스트링)도 이 세 따옴표 문자열로 쓴다.

## 2.4 조건문

지금까지의 프로그램은 위에서 아래로 모든 줄을 실행했다. **조건문**을 쓰면 조건에 따라 **어떤 줄은 실행하고 어떤 줄은 건너뛸** 수 있다.

### 2.4.1 `if`

```python
# if_basic.py
age = int(input("나이: "))
if age >= 19:
    print("성인입니다.")
    print("입장 가능합니다.")
print("안녕히 가세요.")
```

```
나이: 25
성인입니다.
입장 가능합니다.
안녕히 가세요.
```
```
나이: 15
안녕히 가세요.
```

구조는 다음과 같다.

```
if 조건:
    조건이 True일 때 실행할 코드
    (여러 줄 가능)
조건과 상관없이 실행할 코드
```

1장의 들여쓰기 규칙이 그대로 적용된다.

- `if 조건` 끝에 **콜론**(`:`)을 붙인다.
- 조건이 참일 때 실행할 코드는 **공백 4칸 들여쓴다.** 이 들여쓴 덩어리를 **블록**(block)이라고 한다.
- 들여쓰기를 되돌리면 블록이 끝난다. 마지막 `print("안녕히 가세요.")`는 들여쓰지 않았으므로 `if`와 상관없이 항상 실행된다.

콜론을 빠뜨리면 다음 오류가 난다.

```python
if age >= 19
    print("성인입니다.")
```

```
    if age >= 19
                ^
SyntaxError: expected ':'
```

### 2.4.2 `else`

조건이 거짓일 때 실행할 코드가 있으면 `else`를 붙인다.

```python
age = int(input("나이: "))
if age >= 19:
    print("성인입니다.")
else:
    print("미성년자입니다.")
```

`if` 블록과 `else` 블록 중 **정확히 하나만** 실행된다. `else`에는 조건을 쓰지 않으며, `else` 뒤에도 콜론을 붙인다. `else`는 짝이 되는 `if`와 **같은 깊이**로 들여써야 한다.

### 2.4.3 `elif`

경우가 셋 이상이면 `elif`(else if의 줄임말)를 쓴다.

```python
# grade.py
score = int(input("점수: "))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"{score}점은 {grade} 학점입니다.")
```

```
점수: 85
85점은 B 학점입니다.
```

`if`부터 **위에서 아래로 차례로** 조건을 검사하고, **처음으로 참이 되는 블록 하나만** 실행한 뒤 나머지는 모두 건너뛴다. 어느 것도 참이 아니면 `else` 블록을 실행한다.

85점이면 `score >= 90`은 거짓, `score >= 80`은 참이므로 `"B"`가 되고 끝난다. 85는 `score >= 70`도 만족하지만 그 조건은 **검사조차 하지 않는다.** 그래서 `elif`에 `score >= 80 and score < 90`처럼 상한을 쓸 필요가 없다.

**순서가 중요하다.** 조건 순서를 거꾸로 쓰면 어떻게 될까?

```python
if score >= 70:
    grade = "C"
elif score >= 80:
    grade = "B"
elif score >= 90:
    grade = "A"
```

95점도 첫 번째 조건 `score >= 70`에서 참이 되어 `"C"`가 된다. 아래 조건에는 영원히 도달하지 않는다. 범위를 나눌 때는 **좁은(엄격한) 조건부터** 쓰자.

**`elif` 대신 `if`를 여러 개 쓰면** 각각 독립적으로 검사하므로 결과가 다르다.

```python
score = 95
if score >= 90:
    print("A")
if score >= 80:
    print("B")
```

```
A
B
```

"여러 경우 중 하나"를 고를 때는 `if`/`elif`/`else`, "여러 조건을 각각 따로" 검사할 때는 `if`를 여러 개 쓴다.

### 2.4.4 중첩 조건

조건문 블록 안에 다시 조건문을 쓸 수 있다. 들여쓰기가 한 단계 더 깊어진다.

```python
# ticket.py
age = int(input("나이: "))
has_coupon = input("쿠폰이 있나요? (y/n): ") == "y"

if age >= 19:
    if has_coupon:
        price = 8000
    else:
        price = 10000
else:
    price = 5000

print(f"요금: {price:,}원")
```

두 번째 줄에서 `input(...) == "y"`의 결과(`True` 또는 `False`)를 바로 `has_coupon`에 저장했다. 비교의 결과는 불리언 값이므로 이렇게 변수에 담을 수 있다. 이름을 `has_`, `is_`로 시작하면 불리언 변수라는 것이 잘 드러난다.

중첩은 꼭 필요할 때만 쓰자. 두세 단계 이상 깊어지면 읽기 어려워진다. `and`로 조건을 합치면 중첩을 줄일 수 있는 경우가 많다.

```python
# 중첩
if age >= 19:
    if has_coupon:
        print("성인 할인")

# and로 평평하게
if age >= 19 and has_coupon:
    print("성인 할인")
```

### 2.4.5 참·거짓으로 평가되는 값 (truthy / falsy)

`if` 뒤에 꼭 비교식만 쓸 수 있는 것은 아니다. **어떤 값이든** 조건 자리에 쓸 수 있고, 파이썬은 그 값을 참이나 거짓으로 판단한다.

다음 값들은 **거짓**(falsy)으로 취급한다.

| 자료형 | 거짓으로 취급하는 값 |
|---|---|
| 불리언 | `False` |
| 없음 | `None` |
| 숫자 | `0`, `0.0` |
| 문자열 | `""` (빈 문자열) |
| 자료구조 (3장) | `[]`, `()`, `{}`, `set()` (비어 있는 것) |

**이 외의 모든 값은 참**(truthy)이다. 정리하면 "0, 비어 있는 것, 없는 것은 거짓"이다. `bool()`로 직접 확인할 수 있다.

```python
>>> bool(0)
False
>>> bool(42)
True
>>> bool("")
False
>>> bool("hello")
True
>>> bool(None)
False
```

이 성질 덕분에 다음처럼 짧게 쓸 수 있다.

```python
name = input("이름: ").strip()
if name:
    print(f"안녕하세요, {name}님!")
else:
    print("이름을 입력하지 않았습니다.")
```

`if name:`은 `if name != "":`과 같은 뜻이다. "이름이 비어 있지 않으면"으로 읽는다. AI가 만든 코드에서 이런 모양을 자주 봤을 것이다.

**함정 두 가지**

```python
>>> bool("0")
True
>>> bool("False")
True
>>> bool(" ")
True
```

문자열 `"0"`, `"False"`, 공백 한 칸 `" "`은 모두 **비어 있지 않은 문자열**이므로 참이다. `input()`으로 받은 값은 항상 문자열이라는 것을 다시 떠올리자. 사용자가 `0`을 입력해도 `if answer:`는 참이 된다. 숫자로서 0인지 확인하려면 `int()`로 바꾼 뒤 비교해야 한다.

두 번째 함정은 `None`과 `0`의 구분이다.

```python
score = 0
if not score:
    print("점수가 없습니다")    # 0점인데 "없다"고 출력된다!
```

0점은 "점수가 있는데 0"인데, `0`도 거짓이므로 `None`과 같이 처리되었다. 2.1.6에서 본 것처럼 `0`과 `None`을 구분해야 하는 경우에는 `is None`으로 정확히 묻는다.

```python
if score is None:
    print("점수가 없습니다")
```

### 2.4.6 조건 표현식

조건에 따라 **두 값 중 하나를 고르는** 간단한 경우는 한 줄로 쓸 수 있다.

```
참일_때_값 if 조건 else 거짓일_때_값
```

```python
age = 25
status = "성인" if age >= 19 else "미성년자"
print(status)
```

```
성인
```

아래 네 줄과 같은 뜻이다.

```python
if age >= 19:
    status = "성인"
else:
    status = "미성년자"
```

다른 언어의 삼항 연산자(`조건 ? A : B`)에 해당한다. 순서가 "값 – 조건 – 값"이라는 점이 다르다. f-string 안에서도 쓸 수 있다.

```python
count = 1
print(f"{count}개의 파일{'을' if count == 1 else '들을'} 찾았습니다")
```

조건 표현식은 **값 하나를 고르는 짧은 경우**에만 쓰자. 조건이 복잡하거나 경우가 셋 이상이면 일반 `if`/`elif`/`else`가 더 읽기 쉽다.

> **`pass`**: 블록에는 최소 한 줄이 있어야 한다. 아직 무엇을 할지 정하지 않았을 때는 "아무것도 하지 않는다"는 뜻의 `pass`를 적어 둔다.
> ```python
> if age < 0:
>     pass  # 나중에 오류 처리를 넣을 예정
> ```

아이디는 앞뒤 공백을 제거하고 대소문자를 구분하지 않는다(`ADMIN`도 통과). 비밀번호는 정확히 일치해야 한다.

## 2.5 반복문

같은 일을 여러 번 해야 할 때 코드를 여러 번 복사하는 대신 **반복문**을 쓴다. 파이썬에는 `for`와 `while` 두 가지가 있다.

- **`for`** — 정해진 횟수만큼, 또는 정해진 값들을 **하나씩 꺼내며** 반복한다.
- **`while`** — 조건이 **참인 동안** 계속 반복한다. 몇 번 반복할지 미리 모를 때 쓴다.

### 2.5.1 `for`와 `range()`

```python
for i in range(5):
    print(i)
```

```
0
1
2
3
4
```

`range(5)`는 0, 1, 2, 3, 4라는 다섯 개의 수를 만든다. `for`는 이 수를 **하나씩 꺼내서 `i`에 할당하고**, 매번 들여쓴 블록을 실행한다. 블록이 한 번 실행되는 것을 반복 한 **바퀴**(iteration)라고 한다.

```
for 변수 in 반복할_대상:
    매 바퀴 실행할 코드
```

`if`와 마찬가지로 끝에 콜론, 블록은 들여쓰기다. 변수 이름은 마음대로 지을 수 있는데, 단순한 횟수 세기에는 관례적으로 `i`를 쓴다.

**`range()`의 세 가지 모양**

| 모양 | 만드는 수 | 예 | 결과 |
|---|---|---|---|
| `range(끝)` | 0부터 끝 **앞**까지 | `range(5)` | 0, 1, 2, 3, 4 |
| `range(시작, 끝)` | 시작부터 끝 **앞**까지 | `range(2, 6)` | 2, 3, 4, 5 |
| `range(시작, 끝, 간격)` | 간격만큼 건너뛰며 | `range(0, 10, 3)` | 0, 3, 6, 9 |

슬라이싱과 마찬가지로 **끝은 포함하지 않는다.** 그래서 `range(5)`는 정확히 5번 반복한다. 1부터 10까지 원하면 `range(1, 11)`이다.

간격을 음수로 하면 거꾸로 센다.

```python
>>> for i in range(5, 0, -1):
...     print(i)
...
5
4
3
2
1
```

대화형 셸에서 콜론으로 끝나는 줄을 입력하면 프롬프트가 `...`로 바뀌고, 블록을 이어서 입력할 수 있다. 파이썬 3.13 이상의 셸은 들여쓰기를 자동으로 넣어 주고, 3.12에서는 공백 4칸을 직접 입력한다. 블록을 다 입력한 뒤 **아무것도 입력하지 않은 빈 줄에서 Enter**를 누르면 실행된다. (자동 들여쓰기가 남아 있으면 Enter를 한 번 더 누른다.)

**변수를 쓰지 않을 때**: 반복 횟수만 필요하고 `i` 값은 쓰지 않으면 이름을 밑줄 하나(`_`)로 짓는 관례가 있다. "이 값은 쓰지 않는다"는 표시다.

```python
for _ in range(3):
    print("파이팅!")
```

**문자열로 반복**: `for`는 `range()`뿐 아니라 **여러 값이 순서대로 들어 있는 것**이면 무엇이든 반복할 수 있다. 문자열에 쓰면 글자를 하나씩 꺼낸다.

```python
for ch in "파이썬":
    print(ch)
```

```
파
이
썬
```

3장에서 배울 리스트, 튜플, 딕셔너리도 모두 `for`로 반복할 수 있다. 사실 파이썬에서 `for`가 가장 많이 쓰이는 곳은 그쪽이다.

### 2.5.2 누적 패턴

반복문에서 가장 흔한 패턴은 **결과를 담을 변수를 반복 전에 준비하고, 반복하면서 쌓아 가는 것**이다.

```python
# sum_1_to_100.py
total = 0                    # ① 반복 전에 초깃값
for i in range(1, 101):
    total += i               # ② 매 바퀴 누적
print(f"1~100의 합: {total}")  # ③ 반복이 끝난 뒤 결과 사용
```

```
1~100의 합: 5050
```

세 위치를 잘 보자.

- ① `total = 0`은 **반복문 밖, 위에** 있다. 반복문 안에 있으면 매 바퀴 0으로 초기화되어 버린다.
- ② 누적은 **반복문 안**(들여쓴 블록)에 있다.
- ③ 결과 출력은 **반복문 밖, 아래**(들여쓰기를 되돌린 곳)에 있다. 반복문 안에 있으면 100번 출력된다.

이 패턴은 합계뿐 아니라 개수 세기, 문자열 만들기에도 쓴다.

```python
# count_vowels.py
text = input("영문 문장: ").lower()
count = 0
for ch in text:
    if ch in "aeiou":
        count += 1
print(f"모음 개수: {count}")
```

```
영문 문장: Hello Python
모음 개수: 3
```

반복문 안에 조건문이 들어갔다. 들여쓰기가 두 단계(8칸)가 된다는 것을 확인하자.

### 2.5.3 `while`

`while`은 조건이 **참인 동안** 블록을 반복한다. 매 바퀴 시작할 때 조건을 검사하고, 거짓이 되면 반복을 끝낸다.

```python
count = 1
while count <= 5:
    print(count)
    count += 1
print("끝")
```

```
1
2
3
4
5
끝
```

`for`와 달리 `while`은 변수를 바꾸는 일을 **직접** 해야 한다. 위 코드에서 `count += 1`을 빼먹으면 `count`가 영원히 1이므로 조건이 계속 참이고, 반복이 **끝나지 않는다.** 이것을 **무한 루프**라고 한다.

> **무한 루프에서 빠져나오기**: 프로그램이 멈추지 않고 계속 출력하거나 반응이 없으면 터미널에서 **`Ctrl + C`** 를 누른다. (macOS도 `Cmd`가 아니라 `Ctrl`이다.) `KeyboardInterrupt`라는 메시지와 함께 프로그램이 강제로 종료된다. VS Code에서 디버깅 중이라면 중지(`Shift + F5`) 버튼을 누른다.

위 예처럼 횟수가 정해진 반복은 `for i in range(1, 6):`이 더 간단하고 안전하다. `while`은 **언제 끝날지 미리 알 수 없을 때** 쓴다. 대표적인 예가 올바른 입력이 들어올 때까지 다시 묻는 것이다.

```python
# ask_age.py
age_text = input("나이(숫자): ")
while not age_text.isdigit():
    print("숫자만 입력하세요.")
    age_text = input("나이(숫자): ")
age = int(age_text)
print(f"내년에는 {age + 1}살입니다.")
```

```
나이(숫자): 스물다섯
숫자만 입력하세요.
나이(숫자): 25살
숫자만 입력하세요.
나이(숫자): 25
내년에는 26살입니다.
```

몇 번 틀릴지 모르므로 `for`로는 쓸 수 없다.

### 2.5.4 `break`와 `continue`

반복 도중에 흐름을 바꾸는 두 가지 명령이 있다.

- **`break`** — 반복을 **즉시 끝내고** 반복문 다음 줄로 간다.
- **`continue`** — 이번 바퀴의 나머지를 **건너뛰고** 다음 바퀴로 간다.

```python
for i in range(1, 11):
    if i == 5:
        break
    print(i)
print("반복 종료")
```

```
1
2
3
4
반복 종료
```

```python
for i in range(1, 11):
    if i % 3 == 0:
        continue
    print(i, end=" ")
print()
```

```
1 2 4 5 7 8 10 
```

3의 배수일 때 `continue`가 실행되어 `print(i)`를 건너뛰었다.

> `print(i, end=" ")`의 `end=" "`는 출력 뒤에 줄바꿈 대신 공백을 붙이라는 뜻이다. `print()`는 원래 출력 끝에 줄바꿈(`\n`)을 붙이는데, 그것을 바꾼 것이다. 그래서 숫자가 한 줄에 나란히 출력된다. 마지막 `print()`는 줄바꿈을 한 번 넣어서 다음 출력이 새 줄에서 시작하게 한다. (`end=`처럼 이름을 붙여 넘기는 값은 4장 "인자 전달 방식"에서 배운다.)

**`while True`와 `break`**

`while True:`는 조건이 항상 참이므로 무한 루프다. 하지만 블록 안에 `break`를 두면 **원하는 시점에** 빠져나올 수 있다. "일단 하고, 끝낼지 판단한다"는 구조가 필요할 때 가장 많이 쓰는 모양이다.

```python
# calc_loop.py
total = 0
while True:
    text = input("더할 수 (끝내려면 q): ").strip()
    if text == "q":
        break
    if not text.isdigit():
        print("숫자 또는 q를 입력하세요.")
        continue
    total += int(text)
    print(f"  현재 합계: {total}")
print(f"최종 합계: {total}")
```

```
더할 수 (끝내려면 q): 10
  현재 합계: 10
더할 수 (끝내려면 q): abc
숫자 또는 q를 입력하세요.
더할 수 (끝내려면 q): 25
  현재 합계: 35
더할 수 (끝내려면 q): q
최종 합계: 35
```

2.5.3의 `ask_age.py`는 `input()`을 두 번(반복 전과 반복 안) 썼지만, 이 모양은 한 번만 쓴다. 입력 → 끝낼지 확인(`break`) → 잘못된 입력이면 다시(`continue`) → 정상 처리 순서는 메뉴 프로그램, 챗봇의 대화 루프 등에서 그대로 쓰인다. 나중에 LLM API로 챗봇을 만들 때도 바로 이 구조가 뼈대가 된다.

### 2.5.5 중첩 반복

반복문 안에 반복문을 쓸 수 있다. 바깥쪽 한 바퀴마다 안쪽 반복이 **처음부터 끝까지** 돈다.

```python
# gugudan.py
for dan in range(2, 4):
    print(f"--- {dan}단 ---")
    for n in range(1, 10):
        print(f"{dan} x {n} = {dan * n}")
```

```
--- 2단 ---
2 x 1 = 2
2 x 2 = 4
...
2 x 9 = 18
--- 3단 ---
3 x 1 = 3
...
3 x 9 = 27
```

바깥쪽이 2번, 안쪽이 9번이므로 안쪽 블록은 총 2 × 9 = 18번 실행된다.

모양 그리기도 중첩 반복의 대표적인 연습이다.

```python
for row in range(1, 5):
    line = ""
    for col in range(row):
        line += "*"
    print(line)
```

```
*
**
***
****
```

(사실 이 경우는 `print("*" * row)` 한 줄이면 된다. 하지만 중첩 반복의 흐름을 익히는 데 좋은 예다.)

**`break`는 가장 가까운 반복 하나만 끝낸다.** 안쪽 반복에서 `break`하면 안쪽만 끝나고 바깥쪽 반복은 계속된다.

```python
for dan in range(2, 4):
    for n in range(1, 10):
        if n > 3:
            break
        print(f"{dan}x{n}", end=" ")
    print()
```

```
2x1 2x2 2x3 
3x1 3x2 3x3 
```

### 2.5.6 `enumerate()` — 순서 번호와 함께 반복

반복하면서 **몇 번째인지**도 알고 싶을 때가 많다. 직접 세는 변수를 만들 수도 있지만,

```python
index = 0
for ch in "abc":
    print(index, ch)
    index += 1
```

`enumerate()`를 쓰면 번호와 값을 함께 꺼내 준다.

```python
for index, ch in enumerate("abc"):
    print(index, ch)
```

```
0 a
1 b
2 c
```

`for` 뒤에 변수를 **두 개** 쓴 것에 주목하자. `enumerate()`는 매 바퀴 (번호, 값) 한 쌍을 주고, 그 쌍이 두 변수에 나뉘어 담긴다. 이 "나누어 담기"의 정확한 원리는 3장 "튜플"에서 배운다. 지금은 모양을 익혀 두자.

번호를 1부터 시작하고 싶으면 `start=1`을 넣는다. 사람에게 보여 주는 번호는 보통 1부터 시작한다.

```python
menu = "아메리카노,라떼,녹차".split(",")
for number, item in enumerate(menu, start=1):
    print(f"{number}. {item}")
```

```
1. 아메리카노
2. 라떼
3. 녹차
```

### 2.5.7 `zip()` — 여러 개를 나란히 반복

두 묶음을 **같은 순서끼리 짝지어** 반복할 때 `zip()`을 쓴다.

```python
names = ["철수", "영희", "민수"]
scores = [85, 92, 78]

for name, score in zip(names, scores):
    print(f"{name}: {score}점")
```

```
철수: 85점
영희: 92점
민수: 78점
```

(대괄호로 감싼 `["철수", "영희", "민수"]`는 2.3.5에서 미리 본 리스트다. 직접 만드는 방법은 3장에서 배운다.)

첫 바퀴에는 각 묶음의 첫 번째 값끼리, 두 번째 바퀴에는 두 번째 값끼리 짝지어진다. 지퍼(zipper)의 이가 맞물리는 모양을 떠올리면 된다.

**길이가 다르면 짧은 쪽에 맞춰 멈춘다.** 남는 값은 오류 없이 무시된다.

```python
for a, b in zip("abc", "12345"):
    print(a, b)
```

```
a 1
b 2
c 3
```

오류가 나지 않으므로 데이터가 빠진 것을 모르고 지나칠 수 있다는 점을 기억하자.

### 2.5.8 디버거로 반복문 따라가기

1장에서 디버거 사용법을 익히면서 "변수를 배운 뒤 본격적으로 쓴다"고 했다. 반복문은 디버거가 가장 빛나는 곳이다. 머릿속으로 따라가기 어려운 "몇 번째 바퀴에서 값이 어떻게 되는가"를 직접 볼 수 있다.

`ch02` 폴더에 `debug_loop.py`를 만든다.

```python
# debug_loop.py
total = 0
for i in range(1, 6):
    if i % 2 == 0:
        continue
    total += i
print(f"홀수의 합: {total}")
```

1. 3번째 줄(`if i % 2 == 0:`)에 중단점을 찍는다.
2. `F5`로 디버깅을 시작한다.
3. 처음 멈췄을 때 변수 패널에서 `i = 1`, `total = 0`을 확인한다.
4. `F10`(단계 실행)을 여러 번 누르며 실행 위치가 어떻게 움직이는지 본다. `i`가 짝수일 때는 `continue`에서 `total += i`를 건너뛰고 `for` 줄로 돌아가는 것이 보인다.
5. 이번에는 `F5`(계속)를 눌러 본다. 중단점이 반복문 안에 있으므로 **다음 바퀴**에서 다시 멈춘다. `F5`를 누를 때마다 `i`와 `total`이 어떻게 바뀌는지 표로 적어 보자.

| 멈춘 횟수 | `i` | `total` (멈춘 시점) |
|---|---|---|
| 1 | 1 | 0 |
| 2 | 2 | 1 |
| 3 | | |
| 4 | | |
| 5 | | |

**조사식(Watch)**: 왼쪽 디버그 패널의 "조사식(Watch)" 칸에서 `+`를 누르고 `i % 2 == 0` 같은 식을 입력하면, 멈출 때마다 그 식의 값도 보여 준다. 조건이 왜 참인지 거짓인지 확인할 때 유용하다.

반복문이 생각대로 동작하지 않으면 `print()`를 여기저기 넣기 전에 디버거부터 켜 보자. 대부분 "아, 이 바퀴에서 값이 이렇게 되는구나" 하고 바로 원인을 찾게 된다.

정답(1~100 사이의 정수)을 코드에 적어 두고, 사용자가 맞힐 때까지 반복해서 입력받는다. 입력할 때마다 "더 큰 수입니다" / "더 작은 수입니다"를 알려 주고, 맞히면 몇 번 만에 맞혔는지 출력한다.

입력: 25

```

- 숫자가 아닌 값을 입력하면 횟수에 세지 않고 다시 묻는다.
- (선택) 정답을 매번 다르게 하려면 파일 맨 위에 `import random`을 쓰고 `answer = random.randint(1, 100)`으로 정한다. `import`는 4장 "모듈 가져다 쓰기"에서 정식으로 배운다. 여기서는 "1~100 사이의 정수를 무작위로 만드는 한 줄"로만 써 보자.

**4) `word_count.py` — 단어 분석**

영문 문장을 입력받아 단어마다 번호와 글자 수를 출력하고, 가장 긴 단어를 찾는다.

## 정리

| 항목 | 핵심 |
|---|---|
| 변수 | 값에 붙이는 **이름표**. `=`는 오른쪽을 계산해 왼쪽 이름을 붙인다. 이름은 snake_case, 내장 함수 이름은 피한다 |
| 자료형 | `int`, `float`, `str`, `bool`. `type()`으로 확인. 실수는 오차가 있으므로 `==`로 비교하지 않는다 |
| 형 변환 | `int()`, `float()`, `str()`, `bool()`. `int(3.9)`는 버림, 반올림은 `round()` |
| `None` | 값이 없음. `0`이나 `""`과 다르다. 확인은 `is None` |
| 산술 | `/`는 항상 실수, `//`는 몫, `%`는 나머지, `**`는 거듭제곱 |
| 비교·논리 | 비교 결과는 `True`/`False`. `and`, `or`, `not`. 헷갈리면 괄호 |
| `in` | 포함 여부. `"@" in email` |
| `==` / `is` | 값 비교는 `==`, `None` 확인만 `is` |
| 인덱싱·슬라이싱 | 0부터 시작, `-1`은 마지막. `s[시작:끝]`은 끝을 포함하지 않는다. `s[::-1]`은 뒤집기 |
| f-string | `f"{변수}"`, `{x:.2f}`, `{n:,}`, `{s:>10}`, `{x=}` |
| 문자열 메서드 | `strip`, `split`, `join`, `replace`, `find`, `upper`/`lower`. **원본은 바뀌지 않는다** — 결과를 다시 할당 |
| 이스케이프 | `\n`, `\t`, `\\`. Windows 경로는 `r"..."` |
| 조건문 | `if`/`elif`/`else`는 처음 참인 블록 **하나만** 실행. 좁은 조건부터 |
| truthy/falsy | `0`, `""`, `None`, 빈 자료구조는 거짓. `"0"`, `"False"`는 참 |
| `for` | `range(끝)`, `range(시작, 끝, 간격)` — 끝은 포함하지 않는다. 문자열도 반복 가능 |
| `while` | 언제 끝날지 모를 때. 무한 루프는 `Ctrl + C`. `while True` + `break` 패턴 |
| `break` / `continue` | 반복 끝내기 / 이번 바퀴 건너뛰기. 가장 가까운 반복에만 적용 |
| `enumerate` / `zip` | 번호와 함께 반복 / 여러 묶음을 짝지어 반복 (짧은 쪽에 맞춰 멈춤) |
