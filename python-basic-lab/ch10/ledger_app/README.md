# 가계부 요약

가계부 CSV 파일을 읽어 수입·지출·잔액과 지출 분류별 합계를 보여 주고, 분류별 합계를 CSV 파일로 저장하는 명령행 프로그램.

확인한 파이썬: 3.13.2 (macOS 15, Windows 11)

## 설치

macOS

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windows PowerShell

```
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 실행

```
python main.py samples/2026-10.csv
```

요약은 입력 파일 옆에 `파일이름_summary.csv`로 저장된다(예: `samples/2026-10_summary.csv`).

## 입력 파일 형식

UTF-8 CSV. 첫 줄은 `date,kind,category,memo,amount`다.

| 열 | 내용 | 예 |
|---|---|---|
| `date` | 거래 날짜, `YYYY-MM-DD` | `2026-10-05` |
| `kind` | `수입` 또는 `지출` | `지출` |
| `category` | 분류. 비울 수 없다 | `식비` |
| `memo` | 내용. 비워도 된다 | `점심` |
| `amount` | 금액(원). 1 이상의 정수. 숫자만 쓰거나 세 자리마다 쉼표를 넣는다. 쉼표를 넣으면 큰따옴표로 감싼다 | `9500`, `"12,000"` |

## 입력에 따른 동작

| 상황 | 화면 | 종료 코드 |
|---|---|---|
| 정상 | 요약과 표를 보여 주고 요약 파일을 저장한다 | 0 |
| 첫 줄만 있다 | `거래 내역이 없습니다: 파일` | 0 |
| 빈 파일(0바이트) | `파일이 비어 있습니다` (표준 오류) | 1 |
| 첫 줄이 다르다, UTF-8이 아니다 | 원인 (표준 오류) | 1 |
| 큰따옴표의 짝이 맞지 않는 등 CSV 형식이 깨졌다 | 대략의 줄 번호 (표준 오류). 요약 파일은 만들지 않는다 | 1 |
| 값이 형식에 맞지 않는 줄이 있다 | 문제가 있는 줄의 번호와 원인 (표준 오류). 10건이 넘으면 앞의 10건과 나머지 건수. 요약 파일은 만들지 않는다 | 1 |
| 파일이 없다 | `파일이 없습니다: 파일` (표준 오류) | 1 |
| 인자가 없거나 너무 많다 | 사용법 (표준 오류) | 2 |

## 시험

```
python check_samples.py
```

`samples`의 시험 파일 다섯 개(정상, 첫 줄만, 빈 파일, 값이 잘못된 줄, CSV 형식이 깨진 파일)를 읽고 요약한 결과(계산 결과, 오류의 줄 번호와 원인)를 기대한 결과와 비교한다. 화면 출력과 저장한 요약 파일은 확인하지 않는다.
