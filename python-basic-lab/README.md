# 파이썬 기초

[AI 엔지니어 학습 로드맵](../README.md) 2단계 "LLM 응용 서비스 개발"의 첫 항목인 **파이썬 기초**(문법, 자료구조, 함수, 클래스, 예외, 파일 입출력, 모듈/패키지, 가상환경)의 상세 학습 항목이다.

## 학습 목표

1단계 바이브 코딩에서 AI가 만들어 준 코드를 "대략 따라가는" 수준에서 벗어나, 파이썬 코드를 직접 읽고 쓰고 고칠 수 있는 수준에 도달한다. 이후 과정(파이썬 중급, 데이터 처리 기초, 웹·API 기초, LLM API 활용)을 학습하는 데 필요한 기초 문법과 개념을 다룬다.

## 선행 조건

- 1단계 바이브 코딩을 마쳤거나, AI 코딩 도구로 간단한 프로그램을 만들어 본 경험
- 터미널 사용 경험은 필요하지 않다. 이 과정에 필요한 최소한의 터미널 조작은 "시작하기"에서 다루고, 본격적인 CLI 학습은 다음 항목인 "개발 도구"에서 한다.

## 학습 항목

### 1장. 시작하기

- **터미널 최소 조작** — 터미널 열기(macOS 터미널 / Windows PowerShell / VS Code 내장 터미널), 현재 디렉터리 확인·이동(`pwd`, `cd`, `ls`/`dir`), 파일 경로 지정, 명령 실행과 결과 읽기
- **파이썬 설치와 실행** — 파이썬 설치, 버전 확인, 대화형 셸(REPL), 스크립트 파일 실행, VS Code에서 파이썬 실행·디버깅
- **첫 프로그램** — `print()`로 출력, `input()`으로 입력, 주석, 들여쓰기 규칙, 오류 메시지 읽는 법

### 2장. 기본 문법

- **변수와 자료형** — 변수 할당과 이름 규칙, 정수·실수·문자열·불리언, `type()`, 자료형 변환, `None`
- **연산자** — 산술·비교·논리 연산자, 복합 할당, 연산자 우선순위, 정수 나눗셈과 나머지, `in`/`not in`, `==`와 `is`의 차이, `is None`
- **문자열** — 인덱싱·슬라이싱, f-string 포매팅, 주요 메서드(`split`, `join`, `strip`, `replace`, `find`), 이스케이프 문자, 여러 줄 문자열
- **조건문** — `if`/`elif`/`else`, 중첩 조건, 참·거짓으로 평가되는 값(truthy/falsy), 조건 표현식
- **반복문** — `for`와 `range()`, `while`, `break`/`continue`, 중첩 반복, `enumerate()`, `zip()`

### 3장. 자료구조

- **리스트** — 생성·인덱싱·슬라이싱, 추가·삭제·정렬 메서드, 리스트 순회, 중첩 리스트
- **변수와 객체** — 변수는 객체를 가리키는 이름이라는 것, `b = a`는 복사가 아니라 같은 객체를 공유한다는 것(`id()`, `is`로 확인), 가변 객체와 불변 객체, 대입과 복사의 차이, 얕은 복사와 깊은 복사(`copy` 모듈 — 여기서는 `import copy` 한 줄만 먼저 소개하고, import는 20번에서 정식으로 다룬다)
- **튜플** — 불변 시퀀스, 패킹·언패킹, 함수에서 여러 값 반환, 리스트와의 차이
- **딕셔너리** — 키-값 저장·조회·수정·삭제, `get()`, `keys()`/`values()`/`items()` 순회, 중첩 딕셔너리(JSON 형태 데이터)
- **집합** — 중복 제거, 합집합·교집합·차집합, 멤버십 검사
- **자료구조 선택** — 상황에 따라 리스트/튜플/딕셔너리/집합 중 무엇을 쓸지 판단, 가변·불변에 따른 사용상 차이

### 4장. 함수

- **함수 정의와 호출** — `def`, 매개변수와 인자, `return`, 명시적 반환이 없을 때의 `None` 반환, 독스트링
- **인자 전달 방식** — 위치 인자, 키워드 인자, 기본값, 기본값의 평가 시점(정의 시 한 번), 가변 객체를 기본값으로 쓸 때의 문제와 `None` 기본값 패턴, `*args`/`**kwargs`
- **변수의 범위** — 지역 변수와 전역 변수, `global`을 피해야 하는 이유, 함수 안에서 가변 객체 인자를 변경할 때 호출한 쪽에 미치는 영향
- **람다와 함수 객체** — 함수도 값이라는 것, 함수를 변수에 담고 인자로 넘기기, 람다 표현식
- **내장 함수 활용** — `len`, `sum`, `min`/`max`, `isinstance`, `help()`/`dir()`, 함수를 인자로 받는 `sorted`의 `key`, `map`/`filter`
- **모듈 가져다 쓰기** — `import`, `from ... import`, 별칭(`as`), 표준 모듈 사용(`math`, `random`, `datetime`), 공식 문서에서 모듈 사용법 찾기 (직접 모듈을 만드는 것은 "모듈/패키지"에서 다룬다)

### 5장. 클래스

- **클래스와 객체** — `class` 정의, `__init__`, 인스턴스 속성과 메서드, `self`의 의미, 객체 생성과 사용
- **클래스 설계 기초** — 클래스 속성과 인스턴스 속성, `__str__`/`__repr__`, 캡슐화 관례(`_이름`), `@property`(데코레이터는 "붙여서 쓰는 문법"으로만 소개, 구현은 중급에서)
- **상속** — 부모 클래스와 자식 클래스, 메서드 오버라이딩, `super()`, `isinstance()`로 타입 확인
- **데이터 클래스** — 필드 타입 표기(`name: str`, 타입 힌트의 기본 형태), `from dataclasses import dataclass`, `@dataclass`로 데이터 묶음 정의, 일반 클래스와의 차이, 딕셔너리 대신 쓰는 경우

### 6장. 예외

- **예외 처리** — `try`/`except`/`else`/`finally`, 주요 내장 예외(`ValueError`, `TypeError`, `KeyError`, `IndexError`, `FileNotFoundError`), 트레이스백 읽기
- **예외 발생과 정의** — `raise`, 사용자 정의 예외 클래스, 예외를 잡을 때와 그대로 둘 때의 판단

### 7장. 파일 입출력

- **텍스트 파일** — `open()`과 `with` 문, 읽기·쓰기·추가 모드, 줄 단위 처리, 인코딩(UTF-8)
- **경로 다루기** — `pathlib.Path`로 경로 조합·존재 확인·디렉터리 순회, 상대 경로와 절대 경로, 실행 위치에 따라 상대 경로가 달라지는 문제
- **구조화된 파일** — `csv` 모듈로 CSV 읽기·쓰기, `json` 모듈로 JSON 읽기·쓰기(`load`/`dump`), 딕셔너리·리스트와의 변환

### 8장. 모듈/패키지

- **모듈 만들기** — 직접 만든 `.py` 파일을 모듈로 불러오기, 모듈 검색 경로, `if __name__ == "__main__":`
- **표준 라이브러리 더 보기** — `os`, `sys`, `collections`(`Counter`, `defaultdict`), `typing` 기초, 필요한 모듈을 공식 문서에서 찾는 습관
- **패키지 구조** — 디렉터리와 `__init__.py`, 하위 모듈 import, 작은 프로젝트의 파일 나누기

### 9장. 가상환경

- **가상환경과 패키지 관리** — `venv`로 가상환경 만들기·활성화·비활성화, `python -m pip install`(실행 중인 인터프리터에 설치하는 이유), `requirements.txt` 작성과 복원, 프로젝트별로 가상환경을 분리하는 이유
- **실행 환경 확인** — VS Code에서 인터프리터 선택·확인, 터미널이 찾는 파이썬 확인(macOS `which python`, Windows PowerShell `Get-Command python` 또는 `where.exe python`), 실행 중인 파이썬 확인(`sys.executable`), 터미널의 파이썬과 VS Code가 선택한 파이썬이 다를 수 있다는 점, "설치했는데 import가 안 되는" 문제의 원인과 해결
- **외부 패키지 사용** — PyPI에서 패키지 찾기, 문서 읽기, `requests`로 간단한 HTTP 요청 보내기(이후 "웹·API 기초" 항목으로 연결)

### 10장. 마무리

- **종합 실습** — 파일에서 데이터를 읽어 가공하고 결과를 저장하는 작은 CLI 프로그램(예: 가계부, 할 일 관리, 단어 빈도 분석)을 함수와 클래스로 구조화하여 작성
   - 완료 기준
     - 정상 파일, 빈 파일, 잘못된 형식의 입력을 각각 처리하고 적절한 메시지를 출력한다
     - 핵심 함수와 클래스가 각각 무슨 일을 하는지, 왜 그렇게 나눴는지 설명할 수 있다
     - 새 가상환경에서 `requirements.txt`로 의존성을 복원하고 동일하게 실행할 수 있다
   - 선택 활동: 1단계에서 만든 결과물이 파이썬으로 작성된 경우, 그 코드를 다시 읽고 당시 이해하지 못했던 부분을 정리한다
